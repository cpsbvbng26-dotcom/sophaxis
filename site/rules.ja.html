規程の要点（日本語訳）

最終更新：2026-11-11。

これは英語の The policies in brief の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。

この頁は、それぞれの規程を数文にまとめたものです。まとめであって、誰も縛りません。決まりは、下にリンクしたそれぞれの規程です。

利用規約

  • 作品とその掲載の責任は、すべて著者が負います。受理はモデレーションであり、査読ではありません。
  • Sophaxis は何も保証しません。閉じるときは、運営者が動けない場合を除き、30 日以上前にトップの頁で知らせます。
  • 日本法が適用されます。争いは、できる限り話し合いで解決します。まず運営者に書き、運営者は 7 日以内に答えます。
  • 全文：利用規約

個人情報の取り扱い

  • サイトは cookie を使わず、アクセス解析をせず、ほかのサーバーから何も読み込みません。
  • 投稿は公開の GitHub の issue です。ORCID の記録からは、名前・ウェブサイト・業績だけを使います。
  • Sophaxis が使うサービスの一部は日本の外にあり、多くは米国です。規程がそれぞれを挙げています。
  • 全文：個人情報の取り扱いについて

投稿の規程

  • 著者は、受け付けるリポジトリに CC BY 4.0、CC BY-SA 4.0、CC0 1.0 のどれかで預けた作品の DOI で投稿します。投稿者の GitHub のアカウントにつないだ ORCID の記録が要ります。
  • すべての著者の同意が要ります。生成モデルの使用は申告します。モデルは著者になれません。
  • 規程が挙げる場所に住む著者や、そこに滞在する著者には、Sophaxis を提供しません。
  • 全文：投稿の規程

モデレーションの規程

  • モデレーターは、issue の中で公開して判断し、断るときは理由を挙げます。
  • 投稿者は issue で答えることができ、運営者はもう一度見ます。
  • 運営者自身の投稿も同じ決まりでモデレーションを受け、その印が付きます。
  • 全文：モデレーションの規程

ライセンスと著作権の規程

  • 著作権は著者に残ります。Sophaxis は、作品のライセンスのもとで要旨を示し、PDF の写しを置きます。
  • 他者の図・表・長い引用には、許諾か、法の許す使い方が要ります。
  • 記録のデータは自由に再利用できます。サイトの文は CC BY 4.0、コードは MIT です。
  • 全文：ライセンスの規程と著作権の規程

撤回と削除の規程

  • 著者は、載った作品を撤回できます。引用が切れないよう記録は注記つきで残り、PDF の写しは外します。
  • 記録は、法的な理由か著者の求めにより削除できます。削除した記録に何が残るかは、規程が定めます。
  • 全文：撤回の規程と削除の規程
