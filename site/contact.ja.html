運営者

Sophaxis は、日本にいる一人の個人、根本卓哉（Takuya Nemoto）が運営しています。個人の、営利を目的としないプロジェクトです。会社や大学や出版者が運営しているものではありません。運営者は、無報酬のボランティアとして運営しています。いまは唯一のモデレーターでもあります。Sophaxis は、無料のサービスの範囲だけで配信しています。運営者は、Sophaxis を書く道具である Claude Code の料金を、個人で払っています。運営者は、個人の本棚の延長として、趣味で Sophaxis を置いています。Sophaxis がなぜあるのか、それが記録にとって何を意味するのかは、免責事項にあります。

  • ORCID iD：0009-0000-1406-0547
  • GitHub：cpsbvbng26-dotcom

運営者はモデレーターでもあり、サイトとその記録に責任を負います。サイトとそのコードは、運営者の求めにより、Claude Code（Anthropic）で作りました。免責事項を見てください。利用規約が定めるとおり、著者は自分の作品にすべての責任を負います。運営者の投稿も同じ決まりでモデレーションを行い、運営者自身のものである印を付けます。諮問委員会はまだありません。募集は諮問委員の募集にあります。委員は、本人が同意したあと、ORCID iD とともにここに名を載せます。Sophaxis を紹介する人のために、紹介する人のためにと名前・ロゴ・バッジの頁があります。

連絡先

苦情、法的な事柄、個人データについてのことは、公開の issue ではなく、メールで送ります。宛先は、運営者の ORCID の記録にあるアドレスです。個人情報の取り扱いについてが定めるとおり、メールに含まれる個人データは、そのメールに答えるためだけに使います。

  • サイトについての質問・提案・問題：issue。
  • プレプリントや新しい版の投稿：投稿の様式。
  • 記録の誤り：訂正の様式。
  • 作品の著者の一人として、作品を撤回すること：撤回の様式。
  • 作品の著者の一人として、載っている作品の出版された版を報告すること：出版された版の様式。
  • 法的な理由による削除：削除の様式。
  • 公開すべきでないこと：運営者の ORCID の記録にあるアドレスへのメール。

issue は公開されます。issue に個人データを書かないでください。求めのためのメールアドレスは、このサイトではなく、ORCID の記録に置いています。/oai の OAI-PMH の口には、収集者のための別のアドレスがあります。この規格がアドレスを求めるためです。英語か日本語で書いてください。欧州連合のデジタルサービス法（第 11 条・第 12 条）のもとで、当局・欧州委員会・Sophaxis を使う人のための単一の連絡窓口も、運営者の ORCID の記録にあるメールアドレスです。収集者のためのアドレスではありません。運営者は、7 日以内に答えることを目指します。

ほかの場所にある Sophaxis

  • OSF：プロジェクトの頁 Sophaxis: An Independent Overlay Preprint Server があり、その DOI は 10.17605/OSF.IO/MQ7ZA です。この DOI が指すのはプロジェクトであって、載っている作品ではありません。
  • Zenodo：コードと記録を、版を出すたびに保存しています。版 1.0.0 の DOI は 10.5281/zenodo.24033372 です。10.5281/zenodo.24033371 はすべての版を表します。コミュニティ <https://zenodo.org/communities/sophaxis> は、Sophaxis に載っている作品の Zenodo の記録を集めています。これは、Sophaxis が Zenodo と特別な関係にあることを意味するものではありません。
  • GitHub：コード、記録、投稿を収めた公開のリポジトリです。
  • ROAR：Sophaxis は、サウサンプトン大学の Registry of Open Access Repositories の編集の審査を通り、2026-11-06（日本時間）からそこに載っています。記録 27422 です。

セキュリティ

セキュリティの問題は、公開の issue ではなく、メールで送ります。知られる前に直せるようにするためです。見つけたことと、それを再現する手順を書いてください。Sophaxis は報酬を出しません。どの報告にも感謝します。サイトは、同じ連絡先を標準のファイル security.txt でも示しています。

アクセシビリティ

Sophaxis は、Web Content Accessibility Guidelines（WCAG）2.2 のレベル AA を満たすことを目指しています。自動の確認は、明るい配色と暗い配色のそれぞれで、すべての文字の色のコントラストを確かめます。同じ確認は、本文へ飛ぶリンク、キーボードで操作する人に見えるフォーカス、すべての頁の言語、頁ごとに一つの主見出し、すべての表の見出しも確かめます。使いにくいところは、accessibility のラベルを付けた issue か、メールで報告できます。頁が使えないときは、求めに応じて、運営者が同じ情報を別の形で届けます。たとえば、メールでの平文です。

住所

運営者の住所は公開していません。日本の個人情報保護法の定めるとおり、求めがあれば遅滞なく知らせます。メールで求めてください。

サイトが動いている場所

サイトは Vercel が配信し、GitHub の公開のリポジトリから組み立てています。コード、記録、issue は GitHub に保管し、自動の確認はそこで GitHub Actions として動きます。Sophaxis は、GitHub とも Vercel とも、特別な関係を結んでいません。免責事項を見てください。預け先と DOI 登録機関は、Sophaxis がそれらから何を取るかを、専用の頁で読めます。
