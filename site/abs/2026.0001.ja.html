要旨

In a discounted repeated game, the continuation values along a cyclic path of play are the fixed point of the linear operator x ↦ DQx + (I − D)p, with D = δI and Q a cyclic shift. This preprint uses that identity to study the symmetric n-player game in which a player whose k co-players cooperate earns k + 1 by cooperating and k + 2 by defecting. Main results: 1. The three-player rotation scheme, in which exactly one player defects in each period, is a subgame-perfect equilibrium path if and only if δ ≥ 1/φ ≈ 0.618, where φ is the golden ratio. For n players the threshold lies in (1/(n−2) − 2/(n−2)^n, 1/(n−2)). 2. The payoff vector (2, 4, 2) is never an equilibrium payoff. This corrects an example in the author's earlier preprint (https://doi.org/10.5281/zenodo.22058777). 3. With public randomization, (2+t, 4−t, 2+t) is an equilibrium payoff if and only if δ ≥ max(1/2, 1−t). 4. Without randomization, the set of sustainable t passes through three regimes: two points for 1/2 ≤ δ < 1/φ, a countably infinite set at δ = 1/φ, and the full segment for δ ≥ 2/3. Inside the window 1/φ < δ < 2/3 it has positive Hausdorff dimension, with an explicit lower bound. 5. Golden-window conjecture: inside the window the set has Lebesgue measure zero, and its dimension increases continuously from 0 to 1. Numerical evidence is reported. 6. In the linear dilemma with benefit b and cost c, the rotation is sustainable exactly when cooperation is efficient, the three-player threshold is (√(1 + 4c/b) − 1)/2, and the rotation always needs more patience than cooperation by everyone. The literature has not been searched systematically, and some of the results may be known. All proofs are given in full. This is a preprint and has not been peer-reviewed.
