投稿の規程（日本語訳）

最終更新：2026-11-12。

これは英語の Submission Policy の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。このことは、利用規約の「日本国外の方へ」の節に定めています。

投稿の規程は、だれが何を Sophaxis に投稿できるかと、投稿する人が何を確かめるかを定めます。

この頁が引く法令・ライセンス・規約の文は、引いている節の終わりに置いています。日本の法令は、e-Gov 法令 API が示す条文を全文で引いています。ほかの文は、公式の出どころから 2026-11-12 に取り寄せた文を、語のまま引いています。訳は付けていません。原文を取り寄せられなかった条は、引いていないことと、その理由を記しています。

投稿できる人

サイトを配信する Vercel や、投稿を保管する GitHub が、置かれたものを AI のモデルの学習に使うことがあるため、個人情報が心配な方は、投稿しないでください。この利用は、個人情報の取り扱いについてに書いてあります。

作品を投稿できるのは、その作品の著者だけです。Sophaxis は、モデレーターが作品を読む前に、ORCID を通してこれを確かめます。

  • 様式に書かれた ORCID の記録が、issue を開いた GitHub のアカウントにリンクしている。
  • その ORCID iD が作品の著者のものである。DOI のメタデータがそれを著者の一人として挙げているか、ORCID の記録がその DOI を業績に挙げ、名前が著者の一人と合う。

この両方を通らない投稿は載せません。一つ目の確認は、ORCID の記録を管理している人が issue を開いたことを確かめるものです。公的な本人確認ではありません。ORCID iD を持たない著者は投稿できません。2026-11-21 から、13 歳未満の人は投稿できません。18 歳未満の投稿者には、親または保護者の同意が要ります。2026-11-22 から、著者のだれかが下の表の 43 の国と地域に住んでいるか、投稿から掲載までのあいだにそこに滞在している作品は載せません。投稿者は様式でこのことを確かめます。表で 2026-11-26 とした 15 の国と地域については、2026-11-26 からです。滞在には、旅行・出張・留学のような短いものも含みます。滞在も数えるのは、いくつかの国と地域の法令が、そこに住む人だけでなく、そこにいる人にも及ぶためです。たとえば一般データ保護規則の第 3 条第 2 項は、欧州連合にいるデータ主体と書いています。これらの国と地域では、Sophaxis はサービスを提供しません。その国や地域の法令が、そこにいる人へサービスを提供する者に務めを課しているか、課していると報告されていて、Sophaxis はその務めを一つも満たしていないためです。詳しくは個人情報の取り扱いについてにあります。この決まりは、著者がどこに住んでいるか、どこに滞在しているかだけで決まります。国籍・人種・民族その他の個人の属性によるものではありません。どの国籍の著者も、これらの国と地域の外に住み、そこに滞在していなければ投稿できます。これらの国と地域に住んでいるか滞在している著者は、国籍を問わず投稿できません。務めの中身は、現地に代理人を置くこと、個人データを国内に保存すること、現地で登録すること、データを国外へ出す前に条件を満たすことのいずれかです（一般データ保護規則と英国の一般データ保護規則の第 27 条、欧州連合のデジタルサービス法の第 13 条、中国の個人情報保護法の第 53 条、タイの個人データ保護法の第 37 条第 5 号など）。Sophaxis は一人が無報酬で、無料のサービスの範囲で運営していて、どれも備えていません。運営者は、個人情報の取り扱いについての頁が示すとおり、代理人を置かないと決めています。決まりは、こうした務めを求める法令、または求めると報告されている法令のある国と地域には、Sophaxis を提供しないことです。2026-11-26 から、決まりは、Sophaxis が満たせない務めをもう二つ含みます。一つは、個人データを集める前に、運営者の住所か電話番号をそこにいる人へ知らせる務めです。Sophaxis はどちらも公開していません。もう一つは、そこにいる未成年者の個人データを、サービスが確かめた親の同意があるときに限って扱う務め、または扱わない務めです。同じ日から、2026-11-12 に行った 195 の国の法令の調べが見つけたデータ保護法を、公式の所在とほかの一つの経路から取り寄せても原文で読めなかった国と地域にも、Sophaxis を提供しません。表では、そうした国と地域を「取り寄せられない」としています。国や地域を表に足すのは、そうした務めが報告された時点です。法令の原文を読むのを待ちません。表から外すのは、その法令を原文で読み、Sophaxis に及ばないと確かめてからです。表を変えるときは、利用規約のとおり、効力が始まる前にトップの頁で告知します。Sophaxis は投稿者の確認に拠り、著者がどこに住んでいるか、どこに滞在しているかは調べません。著者がこれらの国と地域に住んでいる、または投稿から掲載までのあいだにそこに滞在したと分かったときは、削除の規程に沿って記録を削除し、運営者は代理人についての判断を見直します。2026-11-22 から、著者のだれかがインドに住むか滞在している 18 歳未満の人である作品は載せません。インドの 2025 年デジタル個人データ保護規則の第 10 条は、2027-05-13 から、18 歳未満の人のデータを扱うときに、確認した親の同意を求めます。Sophaxis にはその確認ができません。

2026-11-23 から、新しい作品は、その最初の DOI が登録されてから 6 か月以上たっているときに限り載せます。6 か月は、投稿の issue を開いた日まで、日本時間で数えます。月の同じ日に満了し、短い月ではその月の末日に満了します。最初の DOI とは、投稿された DOI と、そのメタデータが作品の前の版またはすべての版の DOI として挙げる DOI のうち、最も早く登録されたものです。Zenodo ではすべての版の DOI、Figshare では最初の版の DOI がこれに当たります。登録の日は、DataCite または Crossref が記録している日です。メタデータにその日がないとき（Jxiv など）は、運営者が手で確かめます。issue の自動の確認が、これらの日を読み、6 か月を数えます。早すぎる投稿は載せません。6 か月がたったあとに、新しい issue を開き直せます。すでに Sophaxis に載っている作品の新しい版と、2026-11-23 より前に開かれた投稿には掛かりません。

2026-11-23 から、Crossref が撤回・一部撤回・取り下げ・削除を記録している作品は載せません。懸念表明（expression of concern）を記録している作品は運営者に回し、運営者がモデレーションの規程に従って判断します。Crossref は Retraction Watch のデータベースの記録も含んでいます。issue の自動の確認が、投稿された DOI についてこれらの通知を読みます。リポジトリが自分の頁にだけ示し、Crossref に届けていない通知は、この確認では見えません。

言語モデルとその他の生成モデル

言語モデルを使って書いた作品や開発した作品も、一つの条件で受け付けます。使ったことを申告することです。同じ条件は、画像・図・音声・コードを作るモデルを含め、ほかのすべての生成モデルに当てはまります。

申告では、使った道具の名を挙げ、何に使ったかを書きます。たとえば、下書き、翻訳、証明、コード、文献探索、編集、図、画像です。生成モデルを使わなかった場合は、申告にそう書きます。

2026-11-21 から、様式では使った程度も四段階で尋ねます。著者は、当てはまるうちで最も高い段階を選びます。

  • None: no generative model was used.（使っていない）
  • Editing: language editing, translation or proofreading only.（言葉の手直し・翻訳・校正だけ）
  • Assistance: structure, literature search or checking; the authors wrote the text.（構成・文献探索・確認の手助け。文は著者が書いた）
  • Drafting: a generative model drafted text, proofs, code or figures that the authors revised.（生成モデルが文・証明・コード・図の下書きを作り、著者が手を入れた）

記録の頁では、著者が選んだ段階を申告の上に示します。段階は申告の代わりにはなりません。申告では引き続き、道具の名と、それぞれが何をしたかを書きます。「None」の段階は、モデルの名を挙げる申告と並んで成り立ちません。

言語モデルを著者に挙げることはできません。ほかの生成モデルも、著者に挙げることはできません。利用規約が定めるとおり、著者が作品についてすべての責任を負います。

掲載の後に、申告されていない相当の使用が明らかになった場合、記録に注記を付け、著者に申告を足すよう求めます。

研究資金、利益相反、研究倫理、データ

2026-11-24 から、様式は三つの申告を求めます。作品は、三つすべてが書かれているときに限り載せます。issue の自動の確認は、それぞれの欄が埋まっていることを確かめます。書かれた中身は判断しません。

  • 研究資金：作品のすべての資金提供者と助成番号。資金がなかったときは、そのこと。
  • 利益相反：著者の金銭上または個人的な利害で、作品に関わるもの。雇用、顧問、報酬、作品が論じる人との近い関係などです。ないときは、そのこと。
  • 人を対象とする研究と研究倫理：作品が、調査、聞き取り、実験など、人を対象とする研究を含むかどうか。

人を対象とする研究を含む作品は、承認した倫理審査委員会の名を挙げるか、研究を行った場所の規則のもとで承認が要らなかった理由を書かなければなりません。特定できる参加者は、全員が同意していなければならず、申告はそのことを述べます。上に定めるとおり、第三者の個人データを含む作品は受け付けません。

様式は、任意の欄として、作品が拠るデータ、コード、その他の資料の所在（DOI 付きのリポジトリなど）か、それがないことも尋ねます。Sophaxis は著者にそれらを公開するよう勧めますが、求めはせず、確かめもしません。

記録の頁は、それぞれの申告を著者が書いたとおりに示します。Sophaxis は、申告を読む以上には確かめません。申告が真実でないとわかったときは、モデレーションの規程の「研究の公正」に従って扱います。2026-11-24 より前に開かれた投稿には掛かりません。

版と更新

作品は、一つの Sophaxis の番号のもとで一度だけ載せます。その番号は、記録を撤回したり削除したりした後も、ほかの作品に与えることはありません。

新しい版とは、預け先での新しい版のことです。多くの預け先は、版ごとに別の DOI を与えます。arXiv はすべての版に一つの DOI を使い、その DOI は最新の版を指します。その場合、記録は同じ DOI を、版ごとの日付とともに挙げます。新しい版は、既存の記録の更新として投稿します。前の版も載ったままです。

作品が出版されたとき

載っているプレプリントは、後の版が学術誌、会議録、書籍で出版されても、載ったままです。その場合、記録の頁は出版された版を先頭に示します。何であるか、いつどこで出たか、その DOI です。読者には出版された版を引用するよう求め、載っている版をプレプリントとして示します。

出版された版は、著者なら誰でも一人で、出版された版の様式で報告できます。報告は、その著者の ORCID の記録がリンクしている GitHub のアカウントから行います。自動の確認が、報告が著者からのものであることを確かめ、出版された版の DOI のメタデータを読みます。出版された版は、学術誌の論文、会議の論文、書籍の章、書籍のどれかでなければなりません。受け付ける預け先のどれかにあるものであってはならず、記録と共通の著者がいなければなりません。その後、モデレーターがそれを記録し、その判断を issue で公開します。出版された版は投稿のときに書くこともでき、そのときも同じ確認が走ります。

Sophaxis は、学術誌の査読を評価しません。記録は、著者が述べるとおりに書きます。出版された版が査読を受けた、受けていない、または何も述べない、のどれかです。出版者のメタデータが出版された版をプレプリントにリンクしているか、著者が報告しただけかも書きます。

Sophaxis は毎週、Crossref と DataCite のメタデータから、載っているプレプリントにリンクし、共通の著者を持つ出版された版を探します。自分では何も記録しません。著者に報告を求めます。同じ毎週の確認で、記録した出版された版がまだ解決するかも確かめます。出版者が出版された版に撤回、訂正その他の告知を付けた場合、記録の頁にそれを示します。

出版者の中には、出版に際してプレプリントを外したり変えたりするよう著者に求めるものがあります。著者は出版者の条件を確かめます。掲載を終える必要がある場合、著者なら誰でも一人で、撤回の規程に沿って撤回でき、記録の頁は出版された版へのリンクを保ちます。

受け付けないものの例

これらの例は、上の決まりの当てはめ方を示すものです。すべてを挙げたものではなく、決めるのは決まりのほうです。それぞれの組は、モデレーションの規程に沿ってモデレーターが断るときに挙げる理由に対応しています。

著者であること：投稿者は著者でなければならず、著者全員が同意していなければなりません。

  • 同僚の論文を、本人の許しを得ていても、代わりに投稿すること。投稿できるのは著者だけです。
  • 先生、指導教員、著名な著者の論文を、読まれる価値があるからと投稿すること。
  • 研究室のアカウントや二つ目の個人アカウントのように、ORCID の記録がリンクしていない GitHub のアカウントから issue を開くこと。
  • 共著者の ORCID iD や、issue を開く本人以外の ORCID iD を書くこと。
  • DOI のメタデータも ORCID の記録も作品と結び付けていない ORCID iD を書くこと。
  • 共著者が同意していない、または断ったのに、作品を投稿すること。
  • 断られた作品を、新しい GitHub のアカウントを作って別の名で投稿し直すこと。

預け先と DOI：作品は、受け付ける預け先から、自分自身の DOI を得ていなければなりません。

  • 個人のウェブサイト、大学の頁、Google Drive、Dropbox、Academia.edu、ResearchGate にある PDF。
  • 自身の DOI を与えない PhilArchive、PhilSci-Archive、HAL にだけある作品。受け付ける預け先にも預けてください。
  • 学術誌が出版した版の DOI を、預けたものの DOI として書くこと。
  • 別の作品を、載っているプレプリントの出版された版として書くこと。
  • SciELO Preprints ではなく、SciELO の学術誌の論文の DOI。
  • Qeios と ScienceOpen が登録する、査読報告の DOI。
  • 解決しない DOI や、別の作品につながる DOI。

ライセンス：DOI のメタデータに CC BY 4.0、CC BY-SA 4.0、CC0 1.0 のどれかが記されていなければなりません。

  • CC BY-NC 4.0、CC BY-ND 4.0、CC BY-NC-SA 4.0、CC BY-NC-ND 4.0。
  • CC BY 3.0、CC BY 2.0 その他のクリエイティブ・コモンズのライセンスの古い版。
  • arXiv の非独占的ライセンス（arXiv.org perpetual, non-exclusive license）。
  • 「All rights reserved」、または DOI のメタデータにライセンスがまったく無いもの。
  • PDF や預け先の頁にだけ書かれ、DOI のメタデータには無いライセンス。
  • 掲載の後に、受け付けないライセンスへ変えられたもの。毎週の確認がそれを報告し、運営者が調べます。

対象：作品は、主に哲学・数学・論理学・数理哲学・科学哲学に属していなければなりません。

  • 数学を道具として使う、物理学・経済学・計算機科学・工学・生物学・心理学の論文。
  • 機械学習のベンチマーク、ソフトウェアの説明、データセット。
  • 哲学や数学の問いを論じない、文芸批評・歴史・政治的な論評。
  • 哲学の問いを論じずに助言や実践を説く自己啓発や精神的な手引き、政治の宣言文や運動の呼びかけ。

形：作品は、学術論文の通常の形で、題・要旨・参考文献を備えていなければなりません。

  • スライド、ポスター、講義ノート、録画した講演。
  • 参考文献の無いブログの記事や随筆。
  • 要旨だけ、または本文の無い表紙だけ。
  • 互いに関係の無い複数の論文を一つにまとめた預け物。
  • 小説、詩、日記。

申告：生成モデルについての申告は、道具の名を挙げ、何に使ったかを書いていなければなりません。

  • 言語モデルが本文のどこかを下書きし、翻訳し、または編集したのに「None」とすること。
  • 道具の名も、何をしたかも書かず、言語モデルを使ったとだけ述べる申告。
  • 生成モデルで作った図や画像を、申告から漏らすこと。
  • DOI のメタデータや論文で、言語モデルやその他の生成モデルを著者に挙げること。

権利と個人データ：著者は作品の中のすべてを自由に共有できなければならず、作品は他人を晒すものであってはなりません。

  • 書籍・論文・ウェブサイトから、許しを得ずに、引用として認められる範囲を超えて写した図・表・写真。出典を示しても、許しの代わりにはなりません。
  • 出版者が著者の原稿だけの共有を許しているのに、学術誌の論文の出版者による組版の版を出すこと。
  • 同意していない私人の名前、メールアドレス、住所、写真。
  • 参加者を特定できる、調査や聞き取りへの回答。
  • 私的なメッセージ、メール、チャットの画面写し。
  • ほかの研究者の未公開の素材を、その人の同意なく共有すること。

スパムと嫌がらせ。

  • 同じ作品を何度も、または複数の題で投稿すること。
  • issue を埋めるために、多くの投稿を一度に開くこと。
  • 広告、有料のサービスへのリンク、何かを売るために書かれた文。
  • 名を挙げた人を、嫌がらせ、脅し、または中傷する文。
  • 欄にコードやマークアップを置くなどして、様式・自動の確認・サイトを壊そうとすること。
  • ほかの人、機関、学術誌になりすますこと。

版。

  • 新しい版を、既存の Sophaxis の番号の更新としてではなく、新しい作品として投稿すること。
  • 撤回した記録の新しい版。撤回した記録には、新しい版を加えません。

撤回

著者なら誰でも一人で、撤回の規程に沿って、載っている作品を撤回できます。記録は消しません。撤回した作品は撤回の告知とともに記録の頁を保ち、その作品への引用は切れません。著者は代わりに記録を削除させることもでき、その場合は Sophaxis の番号だけが残ります。法的な理由による削除は、削除の規程に従います。

All policies
