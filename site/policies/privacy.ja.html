最終更新：2026-11-14。

取り扱う者

Sophaxis の運営者、根本卓哉です。住所は公開していません。求めがあれば、遅滞なく知らせます。運営者が個人情報保護法の「個人情報取扱事業者」に当たるものとして、同法の定めをすべて守ります。

取り扱う個人情報

  • 投稿の issue に載る GitHub のユーザー名と、投稿の様式に書かれた内容
  • 載せた論文の著者の氏名と ORCID iD（DOI の登録情報から取ります）
  • 本人確認のために読む、ORCID の公開記録のうち、氏名・ウェブサイト・業績
  • 撤回や出版版の報告の様式に書かれた内容
  • 2026-11-21 から、共著者が同意を確かめるコメントに書く GitHub のユーザー名と ORCID iD
  • 2026-11-23 から、初めての投稿を紹介する研究者がコメントに書く GitHub のユーザー名と ORCID iD。その ORCID の公開記録のうち、氏名・ウェブサイト・業績も同じように読みます。これらはその研究者自身の行為で issue に公開されます

本人確認では、ORCID に、公開記録のうち「個人の詳細」（氏名）・「ウェブサイト」・「業績」の部分だけを問い合わせます。「人物」の部分をまとめて問い合わせないので、公開のメールアドレスや国を受け取ることはありません。検査が使うのは氏名・ウェブサイト・業績だけで、ほかは保存せず、どこにも書き写しません。2026-11-14 から、検査は、形を読むために取得する PDF と、DOI のメタデータの所属も、モデレーターへの助言のために読みます。メールアドレス・電話番号・郵便番号の形をした文字列と、Sophaxis を提供しない国と地域を挙げる所属と行を数えます。書くのは数だけで、見つけた文字列も国や地域の名も書かず、何も保存せず、読んだあとファイルを消します。毎週の確認も、サイトにある PDF の写しを同じように読みます。ORCID の記録の国は読みません。サイトは、閲覧者の個人情報を集めません。Cookie も、アクセス解析も使いません。頁には、閲覧者の情報を外へ送るコードもタグもありません。電気通信事業法の外部送信の規律（第 27 条の 12）が掛かるのは、電気通信事業者と、登録も届出も要らないとされる電気通信事業を営む者だけです。そのうちでも、総務省令が定める役務に限られます。役務を使うのに要る情報は、この規律から除かれています。Sophaxis は何にも料金を取らず、サイトから何の収益も得ていません。そのため運営者は、電気通信事業を営んでいないと考えており、第 27 条の 12 は Sophaxis に掛からないと考えています。総務省令（電気通信事業法施行規則）は、2026-11-12 に取り寄せて読みました。この規律が掛かる役務の一つに、不特定の利用者の求めに応じて情報を送り、閲覧に供する役務を挙げています。何も稼がない役務が事業を営むことになるかは、この省令では決まりません。そこで Sophaxis は、この規律が掛かるものとして務めを果たします。頁が閲覧者のブラウザーに送らせる要求ごとに、省令が示すよう求める三つの事項を、ここに書きます。そうした要求は、検索の頁が Sophaxis 自身のサイトに記録の一覧（papers.json）を求めるものだけです。送られる情報は、ブラウザーが要求とともに送るもの（IP アドレス、ブラウザーの名、求めた頁のアドレスなど）です。取り扱うのは、運営者と連絡先の頁に名のある Sophaxis の運営者と、サイトを配る Vercel Inc. です。利用目的は、検索の頁が検索する一覧を渡すことです。省令は、役務の提供に真に必要な情報をこの規律から除いています。運営者は、この要求がそれに当たると考えています。検索の頁は、Sophaxis 自身が配るスクリプトを一つだけ動かします。Sophaxis から記録の一覧を読み、閲覧者のブラウザの中で検索し、どこにも何も送りません。ほかの頁はスクリプトを動かしません。記録の頁には、X・Bluesky・Facebook・LinkedIn・メールへの共有のリンクがあります。どれも各サービスの頁への普通のリンクで、閲覧者がたどるまで何も送られず、たどった先では各サービスの方針が掛かります。Sophaxis は、Vercel のアクセス解析を有効にしていません。記録の頁を含め、どの頁も、閲覧やダウンロードの数を示しません。Sophaxis はその数を持ちません。数を作るアクセス解析を動かさず、Vercel の閲覧の要求の記録から読者を数えることもしません。

投稿・撤回・出版版の報告には、ORCID iD と、その ORCID の記録がリンクする GitHub のアカウントが要ります。これが無いと検査は著者を確かめられず、issue では手続きを進められません。その場合も、各規程のとおりメールで求めることができます。ほかには何も求めません。

  • 2026-11-14 から、投稿された作品やその DOI のメタデータが示す他人の連絡先と国と地域について、数だけの助言をモデレーターに示し、モデレーションの規程を当てはめられるようにするため
  • 2026-11-21 から、同意を確かめる共著者が、その論文の著者本人であることを確かめるため
  • 2026-11-23 から、初めての投稿を紹介する研究者が、その論文の著者でなく、学術誌の論文・本の章・本を持つことを確かめるため
  • 撤回や出版版の報告をする人が、その論文の著者本人であることを確かめるため
  • 論文の記録の頁、著者ごとの頁、一覧と検索を作り、公開するため
  • 記録を feed.xml・papers.json・OAI-PMH（/oai）で再利用できる形にするため
  • 毎週、DOI とライセンスを確かめるため。著者が同意した作品については、頁と PDF の写しを Internet Archive に保存するため（頁が変わったときにも保存します）
  • 新しく載った頁、変わった頁、削除した頁の場所を、検索エンジンに知らせるため
  • 撤回・訂正・削除の求めと、個人情報についての求めに応えるため

  • 問い合わせ・苦情・紛争・安全についての報告に応えるため

ほかの目的には使いません。

公開と第三者への提供

著者の氏名と ORCID iD は、記録の頁で公開します。記録は、feed.xml・papers.json・OAI-PMH でも公開します。OpenAIRE などの収集者は、そこから題・著者・要旨・ライセンスを写します。著者が同意した作品の頁と PDF の写しは、Internet Archive（米国）に保存します。Zenodo に置かれた作品は、Zenodo にある Sophaxis のコミュニティ（https://zenodo.org/communities/sophaxis）にも集めることがあります。コミュニティに記録を出すのは著者です。記録を持つのは Zenodo で、運営はスイスの CERN です。Sophaxis はコミュニティから何も写しません。運営者がそこの記録を書き換えることもありません。投稿の規程が国と地域ごとに示す日（2026-11-22、そのうち 15 の国と地域は 2026-11-26）から、著者のだれかが Sophaxis を提供しない国と地域（投稿の規程の表にあります）に住んでいるか、投稿から掲載までのあいだにそこに滞在した作品については、記録を足す依頼を断ります。その作品は Sophaxis に載らないためです。依頼そのものは、CERN の規約のもとで Zenodo に残ります。投稿の様式で、すべての著者が掲載と、下の「外国にある事業者の利用」に挙げる提供に同意していることを確かめます。Internet Archive への保存は別の同意で、空けておくこともできます。法令に基づく場合を除き、これ以外に個人情報を第三者へ渡すことはありません。ほかの者がすでに写したものは、Sophaxis の手の外にあります。

外国にある事業者の利用

Sophaxis は、外国にある次の事業者のサービスを使います。記録に含まれる個人データが GitHub・Vercel・ORCID・Internet Archive に渡ることと、審査のあいだ投稿の公開されている部分が Anthropic・OpenAI・xAI に渡ることを、個人情報保護法第 28 条の「外国にある第三者への提供」として扱います。投稿の様式で、この頁の情報を示したうえで、著者それぞれの同意を求めます。この確認は 2026-11-21 から必須です。それまでは、運営者以外の著者の作品は、すべての著者が投稿の issue でこの同意を示してから載せます。Internet Archive への保存の同意は、別の欄で尋ねます。空けておくこともでき、そのときは記録をそこに保存せず、robots.txt で Internet Archive に集めないよう求めます。どの著者も、どちらの同意も、削除の issue かメールでいつでも撤回できます。撤回の前に行ったことは、適法なままです。Internet Archive への同意を撤回すると、著者からの求めであることを運営者が確かめたうえで、審査なしに保存をやめます。運営者は、それまでの写しを除くよう Internet Archive に頼みます。GitHub・Vercel・ORCID への提供の同意を撤回すると、記録を削除します。これらが無いと作品を載せられないためです。

  • GitHub（米国）：投稿の受け付けと、記録の保管
  • Vercel（米国）：サイトの配信。閲覧の要求を、IP アドレスを含めて処理します
  • DataCite（ドイツ）・Crossref（米国）：DOI の登録情報を読むため
  • ORCID（米国）：ORCID の公開記録を読むため
  • Internet Archive（米国）：公開した頁と PDF の写しを保存するため
  • OpenAlex（米国）：載せた作品をどう収めているかを、DOI だけで問い合わせるため。人については問い合わせません
  • Anthropic・OpenAI・xAI（いずれも米国）：審査を助けるため。運営者が、投稿の公開されている部分（issue、DOI の登録情報、要旨）を、それぞれの言語モデル Claude・ChatGPT・Grok に手で読ませます。掲載の後には渡しません

それぞれの事業者の個人情報の扱いは、各社の規約によります。米国の制度については、個人情報保護委員会が米国の制度についての情報を公表しており、Sophaxis はこれに拠ります。2021 年 10 月の調査に基づく情報です。委員会は、連邦について「包括的な法令は存在しない。」とし、個別の分野に適用される法令として、電子通信プライバシー法、金融機関についてのグラム・リーチ・ブライリー法、健康情報についての HIPAA を挙げています。EU の十分性認定はありません。APEC の CBPR システムには、2012 年 7 月 25 日から参加しています。委員会は、CBPR システムに参加している国では、APEC のプライバシーフレームワークに沿った法令とそれを執行する機関があると考えられ、民間部門について「個人情報の保護について概ね我が国と同等の保護が期待できる」と説明しています。個人情報の域内保存義務に係る制度と、事業者に政府の情報収集活動への協力義務を課す制度は、委員会の頁ではどちらも挙げられていません。州の法律もあります。委員会の頁は、カリフォルニア州消費者プライバシー法を包括的な法令として挙げ、イリノイ州とニューヨーク州の法令も報告しています。各社の頁にある住所では、GitHub・Vercel・Anthropic はカリフォルニア州に、ORCID はメリーランド州にあります。ドイツは欧州連合の国で、一般データ保護規則（GDPR）が適用されます。各国の個人情報の保護の制度については、個人情報保護委員会が情報を公表しています。

GitHub・Vercel・ORCID について、欧州連合からの移転は、各社がその枠組みの認証を受けている限りで、EU-米国データプライバシーフレームワークについての欧州委員会の十分性認定に基づきます。

GitHub と Vercel が自ら記録を使う場合が二つあり、それぞれの規約に定めがあります。Sophaxis はこれを変えられません。

  • GitHub の利用規約は、issue と公開のリポジトリに置かれたもの（記録を含みます）を、GitHub とその関連会社が、AI の機能と関連会社のモデルの学習に使うことを認めています（D.4）。公開の内容について、これを止める設定はありません（J.3）。
