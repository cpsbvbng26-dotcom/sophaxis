個人情報の取り扱いについて

最終更新：2026-11-07。

Sophaxis の個人情報の取り扱いを、日本の個人情報保護法の項目に沿って書いたものです。中身は英語の Privacy Policy と同じです。

取り扱う者

Sophaxis の運営者、根本卓哉です。住所は公開していません。求めがあれば、遅滞なく知らせます。運営者が個人情報保護法の「個人情報取扱事業者」に当たるものとして、同法の定めをすべて守ります。

取り扱う個人情報

  • 投稿の issue に載る GitHub のユーザー名と、投稿の様式に書かれた内容
  • 載せた論文の著者の氏名と ORCID iD（DOI の登録情報から取ります）
  • 本人確認のために読む、ORCID の公開記録のうち、氏名・ウェブサイト・業績
  • 撤回や出版版の報告の様式に書かれた内容
  • 2026-11-21 から、共著者が同意を確かめるコメントに書く GitHub のユーザー名と ORCID iD

本人確認では、ORCID に公開記録の「人物」と「業績」の部分を問い合わせます。ORCID は、そこに公開されているものをすべて返します。公開のメールアドレスや国が入ることがあります。検査が使うのは氏名・ウェブサイト・業績だけで、ほかは保存せず、どこにも書き写しません。サイトは、閲覧者の個人情報を集めません。Cookie も、アクセス解析も使いません。頁には、閲覧者の情報を外へ送るコードもタグもありません。電気通信事業法の外部送信の規律（第 27 条の 12）に当たるものはありません。

投稿・撤回・出版版の報告には、ORCID iD と、その ORCID の記録がリンクする GitHub のアカウントが要ります。これが無いと検査は著者を確かめられず、issue では手続きを進められません。その場合も、各規程のとおりメールで求めることができます。ほかには何も求めません。

利用目的

  • 投稿者が、その論文の著者本人であることを確かめるため
  • 2026-11-21 から、同意を確かめる共著者が、その論文の著者本人であることを確かめるため
  • 撤回や出版版の報告をする人が、その論文の著者本人であることを確かめるため
  • 論文の記録の頁、著者ごとの頁、一覧と検索を作り、公開するため
  • 記録を feed.xml・papers.json・OAI-PMH（/oai）で再利用できる形にするため
  • 毎週、DOI とライセンスを確かめ、頁と PDF の写しを Internet Archive に保存するため（頁が変わったときにも保存します）
  • 新しく載った頁、変わった頁、削除した頁の場所を、検索エンジンに知らせるため
  • 取り下げ・訂正・削除の求めと、個人情報についての求めに応えるため

ほかの目的には使いません。

公開と第三者への提供

著者の氏名と ORCID iD は、記録の頁で公開します。記録は、feed.xml・papers.json・OAI-PMH でも公開します。OpenAIRE などの収集者は、そこから題・著者・要旨・ライセンスを写します。頁と PDF の写しは、Internet Archive（米国）に保存します。投稿の様式で、すべての著者がこれらに同意していることを確かめています。法令に基づく場合を除き、これ以外に個人情報を第三者へ渡すことはありません。ほかの者がすでに写したものは、Sophaxis の手の外にあります。

外国にある事業者の利用

Sophaxis は、外国にある次の事業者のサービスを使います。記録に含まれる個人データが GitHub・Vercel・ORCID・Internet Archive に渡ることを、個人情報保護法第 28 条の「外国にある第三者への提供」として扱います。この頁の情報を示したうえで、著者それぞれの同意を得ます。

  • GitHub（米国）：投稿の受け付けと、記録の保管
  • Vercel（米国）：サイトの配信。閲覧の要求を、IP アドレスを含めて処理します
  • DataCite（ドイツ）・Crossref（米国）：DOI の登録情報を読むため
  • ORCID（米国）：ORCID の公開記録を読むため
  • Internet Archive（米国）：公開した頁と PDF の写しを保存するため

それぞれの事業者の個人情報の扱いは、各社の規約によります。米国には、個人情報についての連邦の一般法がありません。州ごとの法律があります。ドイツは欧州連合の国で、一般データ保護規則（GDPR）が適用されます。各国の個人情報の保護の制度については、個人情報保護委員会が情報を公表しています。

各事業者が個人情報を守るために講じている措置は、それぞれの方針にあります。

  • GitHub：GitHub General Privacy Statement。EU-米国データプライバシーフレームワークに従うと述べています。
  • Vercel：Vercel Privacy Notice。EU-米国データプライバシーフレームワークに従うと述べています。
  • ORCID：ORCID Privacy Policy。毎年、EU-米国データプライバシーフレームワークの基準で評価を受けていると述べています。
  • Crossref：Crossref privacy
  • Internet Archive：Terms of Use

メールでの求めは、Apple のメールの受信箱（iCloud メール、米国）に届きます。応えることと、応えたことを示すのに要る間だけ、そこに置きます。Apple が講じている措置は、Apple のプライバシーポリシーにあります。

Vercel は、Sophaxis への閲覧の要求の記録（IP アドレスを含みます）を持っています。運営者はこれを見ることができ、不具合を見つけて直すためだけに使います。

安全のための措置

記録は、DOI の登録情報など、すでに公開されている情報だけで作ります。投稿の自動の検査は、読むものを ORCID の氏名・ウェブサイト・業績に限り、ほかを書き写しません。検査に与える権限は、必要な最小限にしています。記録を変えられるのは、運営者だけです。ただし、削除依頼が個人情報の露出を報告したときは、削除の方針の自動の手順が要旨と PDF の写しを下げます。法令が報告を求める漏えいが起きたときは、個人情報保護委員会に報告し、本人に知らせます。

講じている措置を、個人情報保護委員会の区分で示します。

  • 組織的な措置：個人データを扱うのは運営者一人で、運営者が責任を負います。記録の変更は、どれも公開のコミットかプルリクエストとして残ります。
  • 人的な措置：運営者のほかに、Sophaxis の個人データを扱う人はいません。
  • 物理的な措置：Sophaxis は、自前のサーバーも紙の記録も持ちません。記録は GitHub のリポジトリに、サイトは Vercel にあります。
  • 技術的な措置：自動の手順が持つ鍵は、GitHub が実行ごとに渡す最小限の権限のトークンだけです。Vercel に残る以前の版のサイトは、公開していません。
  • 外的環境の把握：「外国にある事業者の利用」に示したとおりです。

自動の処理

自動の検査は、公開されている記録を照らし合わせ、その結果を issue に書くだけです。人についての判断はしません。人に法的な効果、またはそれに近い重大な影響を与える判断を、自動の処理だけで下すことはありません。運営者の判断の前に動く手順が一つだけあります。削除依頼が個人情報の露出を報告したとき、要旨と PDF の写しを下げる手順です。本人を守るためのもので、依頼が認められなければ元に戻します。自動の手順は、What runs by itself の頁にすべて挙げています。

保存の期間

記録は、引用が壊れないよう、期限を設けずに保ちます。削除の求めがあれば、削除の規程に沿って記録を削除します。著者の求めでも削除します。削除した記録に残るのは、Sophaxis の番号と削除の日だけです。公開のリポジトリの履歴と、Internet Archive の保存には、以前の版が残ります。運営者は、GitHub と Internet Archive にその削除を頼みます。

開示・訂正・利用停止・削除の求め

本人は、Sophaxis が持つ自分の個人データについて、開示・訂正・利用の停止・削除を求めることができます。求めは、削除の issue で受け付けます。issue は公開されるので、個人情報は書かず、Sophaxis の id と求めの種類だけを書く形にします。公開の場で求めにくいときは、運営者の ORCID の記録にあるメールアドレスへ送る形でも受け付けます。OAI-PMH の入口にも、収集者のためのアドレスがあります。この規格がアドレスを求めるためです。個人情報についての求めは、ORCID の記録のアドレスで受け付けます。運営者は、7 日以内に応えることを目安にします。求めに費用はかかりません。個人情報の扱いへの苦情も、同じアドレスで受け付けます。個人情報保護委員会に相談することもできます。

欧州連合と英国の人へ

欧州連合と英国の人については、この取り扱いの根拠は正当な利益です。著者を確かめることと、公開の学術記録を保つことです。記録は、学術記録を保つために残します。一般データ保護規則は、記録の保管、研究、表現の自由のための保存を認めています（第 17 条第 3 項）。十分性の認定もほかの保護措置もない欧州連合の外への移転は、著者の明示の同意に基づきます（第 49 条第 1 項 a）。Internet Archive への移転がこれに当たります。本人は、自分の個人データの利用に異議を述べることができます。自国のデータ保護機関に苦情を申し立てることもできます。異議は、削除の規程に沿って扱います。欧州連合と英国に代理人（第 27 条）は置いていません。置かないと決めています。代理人は、有料のサービスか、欧州連合や英国にいて Sophaxis の責任を引き受ける人になります。Sophaxis は、無報酬で、無料の範囲で運営しています。それらの地域の人は、運営者の ORCID の記録にあるメールアドレスへ、英語か日本語で直接連絡できます。運営者は、その連絡にも、データ保護機関からの連絡にも、代理人に代わって自ら応えます。取り扱いの記録は、公開のリポジトリの docs/records-of-processing.md に置いています。

この方針の変更

この方針を変えたときは、この頁の日付を改めます。過去の版は、公開のリポジトリに残ります。

All policies
