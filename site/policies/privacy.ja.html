個人情報の取り扱いについて

最終更新：2026-11-11。

Sophaxis の個人情報の取り扱いを、日本の個人情報保護法の項目に沿って書いたものです。英語の Privacy Policy の訳で、項目を日本の個人情報保護法に沿って並べ替えてあります。英語と違うところは、英語が優先します。

この頁が引く法令・ライセンス・規約の文は、引いている節の終わりに置いています。日本の法令は、e-Gov 法令 API が示す条文を全文で引いています。ほかの文は、公式の出どころから 2026-11-11 に取り寄せた文を、語のまま引いています。訳は付けていません。原文を取り寄せられなかった条は、引いていないことと、その理由を記しています。

取り扱う者

Sophaxis の運営者、根本卓哉です。住所は公開していません。求めがあれば、遅滞なく知らせます。運営者が個人情報保護法の「個人情報取扱事業者」に当たるものとして、同法の定めをすべて守ります。

取り扱う個人情報

  • 投稿の issue に載る GitHub のユーザー名と、投稿の様式に書かれた内容
  • 載せた論文の著者の氏名と ORCID iD（DOI の登録情報から取ります）
  • 本人確認のために読む、ORCID の公開記録のうち、氏名・ウェブサイト・業績
  • 撤回や出版版の報告の様式に書かれた内容
  • 2026-11-21 から、共著者が同意を確かめるコメントに書く GitHub のユーザー名と ORCID iD
  • 2026-11-23 から、初めての投稿を紹介する研究者がコメントに書く GitHub のユーザー名と ORCID iD。その ORCID の公開記録のうち、氏名・ウェブサイト・業績も同じように読みます。これらはその研究者自身の行為で issue に公開されます

本人確認では、ORCID に、公開記録のうち「個人の詳細」（氏名）・「ウェブサイト」・「業績」の部分だけを問い合わせます。「人物」の部分をまとめて問い合わせないので、公開のメールアドレスや国を受け取ることはありません。検査が使うのは氏名・ウェブサイト・業績だけで、ほかは保存せず、どこにも書き写しません。サイトは、閲覧者の個人情報を集めません。Cookie も、アクセス解析も使いません。頁には、閲覧者の情報を外へ送るコードもタグもありません。電気通信事業法の外部送信の規律（第 27 条の 12）に当たるものはありません。検索の頁は、Sophaxis 自身が配るスクリプトを一つだけ動かします。Sophaxis から記録の一覧を読み、閲覧者のブラウザの中で検索し、どこにも何も送りません。ほかの頁はスクリプトを動かしません。記録の頁には、X・Bluesky・Facebook・LinkedIn・メールへの共有のリンクがあります。どれも各サービスの頁への普通のリンクで、閲覧者がたどるまで何も送られず、たどった先では各サービスの方針が掛かります。Sophaxis は、Vercel のアクセス解析を有効にしていません。記録の頁を含め、どの頁も、閲覧やダウンロードの数を示しません。Sophaxis はその数を持ちません。数を作るアクセス解析を動かさず、Vercel の閲覧の要求の記録から読者を数えることもしません。

投稿・撤回・出版版の報告には、ORCID iD と、その ORCID の記録がリンクする GitHub のアカウントが要ります。これが無いと検査は著者を確かめられず、issue では手続きを進められません。その場合も、各規程のとおりメールで求めることができます。ほかには何も求めません。

利用目的

  • 投稿者が、その論文の著者本人であることを確かめるため
  • 2026-11-21 から、同意を確かめる共著者が、その論文の著者本人であることを確かめるため
  • 2026-11-23 から、初めての投稿を紹介する研究者が、その論文の著者でなく、学術誌の論文・本の章・本を持つことを確かめるため
  • 撤回や出版版の報告をする人が、その論文の著者本人であることを確かめるため
  • 論文の記録の頁、著者ごとの頁、一覧と検索を作り、公開するため
  • 記録を feed.xml・papers.json・OAI-PMH（/oai）で再利用できる形にするため
  • 毎週、DOI とライセンスを確かめるため。著者が同意した作品については、頁と PDF の写しを Internet Archive に保存するため（頁が変わったときにも保存します）
  • 新しく載った頁、変わった頁、削除した頁の場所を、検索エンジンに知らせるため
  • 撤回・訂正・削除の求めと、個人情報についての求めに応えるため
  • サイトを配信し、Vercel の閲覧の要求の記録から不具合を見つけて直すため
  • 問い合わせ・苦情・紛争・安全についての報告に応えるため

ほかの目的には使いません。

公開と第三者への提供

著者の氏名と ORCID iD は、記録の頁で公開します。記録は、feed.xml・papers.json・OAI-PMH でも公開します。OpenAIRE などの収集者は、そこから題・著者・要旨・ライセンスを写します。著者が同意した作品の頁と PDF の写しは、Internet Archive（米国）に保存します。Zenodo に置かれた作品は、Zenodo にある Sophaxis のコミュニティ（https://zenodo.org/communities/sophaxis）にも集めることがあります。コミュニティに記録を出すのは著者です。記録を持つのは Zenodo で、運営はスイスの CERN です。Sophaxis はコミュニティから何も写しません。運営者がそこの記録を書き換えることもありません。2026-11-22 から、著者のだれかが Sophaxis を提供しない国と地域（投稿の規程の表にあります）に住んでいるか、投稿から掲載までのあいだにそこに滞在した作品については、記録を足す依頼を断ります。その作品は Sophaxis に載らないためです。依頼そのものは、CERN の規約のもとで Zenodo に残ります。投稿の様式で、すべての著者が掲載と、下の「外国にある事業者の利用」に挙げる提供に同意していることを確かめます。Internet Archive への保存は別の同意で、空けておくこともできます。法令に基づく場合を除き、これ以外に個人情報を第三者へ渡すことはありません。ほかの者がすでに写したものは、Sophaxis の手の外にあります。

外国にある事業者の利用

Sophaxis は、外国にある次の事業者のサービスを使います。記録に含まれる個人データが GitHub・Vercel・ORCID・Internet Archive に渡ることと、審査のあいだ投稿の公開されている部分が Anthropic・OpenAI・xAI に渡ることを、個人情報保護法第 28 条の「外国にある第三者への提供」として扱います。投稿の様式で、この頁の情報を示したうえで、著者それぞれの同意を求めます。この確認は 2026-11-21 から必須です。それまでは、運営者以外の著者の作品は、すべての著者が投稿の issue でこの同意を示してから載せます。Internet Archive への保存の同意は、別の欄で尋ねます。空けておくこともでき、そのときは記録をそこに保存せず、robots.txt で Internet Archive に集めないよう求めます。どの著者も、どちらの同意も、削除の issue かメールでいつでも撤回できます。撤回の前に行ったことは、適法なままです。Internet Archive への同意を撤回すると、著者からの求めであることを運営者が確かめたうえで、審査なしに保存をやめます。運営者は、それまでの写しを除くよう Internet Archive に頼みます。GitHub・Vercel・ORCID への提供の同意を撤回すると、記録を削除します。これらが無いと作品を載せられないためです。

  • GitHub（米国）：投稿の受け付けと、記録の保管
  • Vercel（米国）：サイトの配信。閲覧の要求を、IP アドレスを含めて処理します
  • DataCite（ドイツ）・Crossref（米国）：DOI の登録情報を読むため
  • ORCID（米国）：ORCID の公開記録を読むため
  • Internet Archive（米国）：公開した頁と PDF の写しを保存するため
  • OpenAlex（米国）：載せた作品をどう収めているかを、DOI だけで問い合わせるため。人については問い合わせません
  • Anthropic・OpenAI・xAI（いずれも米国）：審査を助けるため。運営者が、投稿の公開されている部分（issue、DOI の登録情報、要旨）を、それぞれの言語モデル Claude・ChatGPT・Grok に手で読ませます。掲載の後には渡しません

それぞれの事業者の個人情報の扱いは、各社の規約によります。米国には、個人情報についての連邦の一般法がありません。州ごとの法律があります。国全体で個人情報を受け持つ一つの機関はなく、本人が持つ権利は、州と分野によって違います。ドイツは欧州連合の国で、一般データ保護規則（GDPR）が適用されます。各国の個人情報の保護の制度については、個人情報保護委員会が情報を公表しています。

各事業者が個人情報を守るために講じている措置は、それぞれの方針にあります。

  • GitHub：GitHub General Privacy Statement。EU-米国データプライバシーフレームワークに従うと述べています。
  • Vercel：Vercel Privacy Notice。EU-米国データプライバシーフレームワークに従うと述べています。
  • ORCID：ORCID Privacy Policy。毎年、EU-米国データプライバシーフレームワークの基準で評価を受けていると述べています。
  • Crossref：Crossref privacy
  • Internet Archive：Terms of Use。受け取るのは公開の頁と PDF の写しだけで、記録がすでに公開している以上の個人データは含みません。Internet Archive が個人情報を守るために講じている措置については、情報を示すことができません。その規約はスクリプトを動かさないと読めず、ほかにその措置を述べたものも見つからなかったためです。

GitHub・Vercel・ORCID について、欧州連合からの移転は、各社がその枠組みの認証を受けている限りで、EU-米国データプライバシーフレームワークについての欧州委員会の十分性認定に基づきます。

GitHub と Vercel が自ら記録を使う場合が二つあり、それぞれの規約に定めがあります。Sophaxis はこれを変えられません。

  • GitHub の利用規約は、issue と公開のリポジトリに置かれたもの（記録を含みます）を、GitHub とその関連会社が、AI の機能と関連会社のモデルの学習に使うことを認めています（D.4）。公開の内容について、これを止める設定はありません（J.3）。
  • Vercel の利用規約は、Sophaxis を配信している無料の Hobby プランでは、サイトの内容（記録を含みます）を、Vercel が AI と機械学習のモデルの学習に使い、そのために第三者に渡すことを認めています。アカウントのチームの設定でこれを止めたときは別です（第 3 条）。Sophaxis のアカウントで、この設定を切ったことは確かめていません。

これらの利用で個人情報が心配な方は、投稿しないでください。著者として載ることにも同意しないでください。Sophaxis は、GitHub と Vercel なしには作品を載せられないためです。載っている作品の著者は、いつでも同意を撤回でき、そのときは記録を削除します（上のとおり）。

メールでの求めは、Apple のメールの受信箱（iCloud メール、米国）に届きます。応えることと、応えたことを示すのに要る間だけ、そこに置きます。Apple が講じている措置は、Apple のプライバシーポリシーにあります。欧州連合の人がメールを書くと、それは日本にいる運営者（日本には欧州委員会の十分性認定があります）と、米国の Apple の受信箱に届きます。Apple は、欧州経済領域・英国・スイスで集めた個人データの国際移転は標準契約条項によると述べています。

Vercel は、Sophaxis への閲覧の要求の記録（IP アドレスを含みます）を持っています。運営者はこれを見ることができ、不具合を見つけて直すためだけに使います。

受信箱の Apple と、閲覧の要求の記録の Vercel は、Sophaxis のために個人データを扱っており、どちらも契約で扱わないと定められてはいません。個人情報保護委員会の Q&A 7-53 の読み方に沿って、Sophaxis は両者をその取り扱いの委託先として扱い、個人情報保護法第 25 条により監督します。各社は講じている措置を公表しています。Vercel はデータ処理補遺の別表 2 に、Apple はプライバシーポリシーに書いています。毎週、自動の手順が Vercel と Apple のプライバシーの方針の最終更新日を読みます。日付が変われば issue が開き、運営者が方針を読み直して、そのサービスを使い続けてよいかを決めます。

条文　個人情報の保護に関する法律 第28条

（外国にある第三者への提供の制限） 第二十八条 個人情報取扱事業者は、外国（本邦の域外にある国又は地域をいう。以下この条及び第三十一条第一項第二号において同じ。）（個人の権利利益を保護する上で我が国と同等の水準にあると認められる個人情報の保護に関する制度を有している外国として個人情報保護委員会規則で定めるものを除く。以下この条及び同号において同じ。）にある第三者（個人データの取扱いについてこの節の規定により個人情報取扱事業者が講ずべきこととされている措置に相当する措置（第三項において「相当措置」という。）を継続的に講ずるために必要なものとして個人情報保護委員会規則で定める基準に適合する体制を整備している者を除く。以下この項及び次項並びに同号において同じ。）に個人データを提供する場合には、前条第一項各号に掲げる場合を除くほか、あらかじめ外国にある第三者への提供を認める旨の本人の同意を得なければならない。 この場合においては、同条の規定は、適用しない。
２ 個人情報取扱事業者は、前項の規定により本人の同意を得ようとする場合には、個人情報保護委員会規則で定めるところにより、あらかじめ、当該外国における個人情報の保護に関する制度、当該第三者が講ずる個人情報の保護のための措置その他当該本人に参考となるべき情報を当該本人に提供しなければならない。
３ 個人情報取扱事業者は、個人データを外国にある第三者（第一項に規定する体制を整備している者に限る。）に提供した場合には、個人情報保護委員会規則で定めるところにより、当該第三者による相当措置の継続的な実施を確保するために必要な措置を講ずるとともに、本人の求めに応じて当該必要な措置に関する情報を当該本人に提供しなければならない。

安全のための措置

記録は、DOI の登録情報など、すでに公開されている情報だけで作ります。投稿の自動の検査は、読むものを ORCID の氏名・ウェブサイト・業績に限り、ほかを書き写しません。検査に与える権限は、必要な最小限にしています。記録を変えられるのは、運営者だけです。ただし、削除依頼が個人情報の露出を報告したときは、削除の規程の自動の手順が記録の頁（題・著者・要旨・PDF の写し）を下げます。法令が報告を求める漏えいが起きたときは、個人情報保護委員会に報告し、本人に知らせます。報告が要るのは、要配慮個人情報を含むとき、不正に使われると財産の損害が生じうるとき、運営者のアカウントへの攻撃のような不正の目的による行為で漏れたとき、1,000 人を超えるときです。運営者は、知ったあと速やかに報告し、30 日以内に、不正の目的による行為のおそれがあるときは 60 日以内に、確かな報告をします。

講じている措置を、個人情報保護委員会の区分で示します。

  • 組織的な措置：個人データを扱うのは運営者一人で、運営者が責任を負います。記録の変更は、どれも公開のコミットかプルリクエストとして残ります。
  • 人的な措置：運営者のほかに、Sophaxis の個人データを扱う人はいません。モデレーターを招く前に、運営者は、モデレーターが扱える個人データと、運営者がどう監督するかをここに書きます。
  • 物理的な措置：Sophaxis は、自前のサーバーも紙の記録も持ちません。記録は GitHub のリポジトリに、サイトは Vercel にあります。
  • 技術的な措置：自動の手順が持つ鍵は、GitHub が実行ごとに渡す最小限の権限のトークンだけです。Vercel に残る以前の版のサイトは、公開していません。リポジトリを変えられる唯一のアカウントである運営者の GitHub アカウントは、二段階認証を使っています。サイトを配る Vercel には、運営者はこの GitHub アカウントでログインしています。
  • 外的環境の把握：「外国にある事業者の利用」に示したとおりです。

自動の処理

自動の検査は、公開されている記録を照らし合わせ、その結果を issue に書くだけです。人についての判断はしません。人に法的な効果、またはそれに近い重大な影響を与える判断を、自動の処理だけで下すことはありません。審査を助ける言語モデルは、判断をしません。投稿についての判断は、モデレーションの規程のとおり、すべて人が下します。運営者の判断の前に動く手順が一つだけあります。削除依頼が個人情報の露出を報告したとき、記録の頁（題・著者・要旨・PDF の写し）を下げる手順です。本人を守るためのもので、依頼が認められなければ元に戻します。自動の手順は、自動で動く手順の頁にすべて挙げています。

2026-11-22 から、Sophaxis は、投稿の規程の表にあるほかの国と地域の人にもサービスを提供しません。そこの法令は、現地の代理人、国内での個人データの保存、現地での登録、データを国外へ出す前の条件のいずれかを求めているか、求めると報告されています。Sophaxis はどれも満たしていません。国や地域は、そうした務めが報告された時点で表に足し、法令を原文で読んでから外します。ロシアの連邦法第 152-FZ 号は、国外に住むロシア国民のデータにも、本人が処理に同意していれば及びます（第 1 条第 1.1 項）。Sophaxis は住んでいる場所と滞在している場所で決め、国籍は尋ねないので、この部分には対応していません。ロシアの当局から指摘があれば、運営者は判断を見直します。2026-11-22 から、著者のだれかがインドに住むか滞在している 18 歳未満の人である作品は載せません。インドの 2025 年デジタル個人データ保護規則の第 10 条は、2027-05-13 から、18 歳未満の人のデータを扱うときに、確認した親の同意を求めます。Sophaxis にはその確認ができません。これは住んでいる場所と滞在している場所だけで決まり、国籍・人種・民族その他の個人の属性によるものではありません。それでも、上に書いた本人の求めには、当てはまる限り応えます。
