利用規約（日本語訳）

最終更新：2026-11-08。

これは英語の Terms of Use の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。このことは、下の「日本国外の方へ」の節に定めています。

この規約が及ぶ人

この規約は、Sophaxis を読む人と、Sophaxis に投稿する人のすべてに及びます。サイトを使うことは、この規約を受け入れることを意味します。ほかの規程も、この規約の一部です。

Sophaxis が提供するもの

Sophaxis は、哲学・数学・論理学・数理哲学・科学哲学のプレプリントを載せます。載せた作品のそれぞれに、記録の頁、検索、フィードを与えます。預け先が許す場合は、PDF の写しも置きます。これらを無料で行います。

著者がすべての責任を負う

著者は、自分の作品と、それを Sophaxis に載せることについて、すべての責任を負います。次のものを含みます。

  • 作品の内容。主張・証明・引用・計算・図のすべてを含みます。
  • その版をそのライセンスで共有する権利と、出版者の許諾。
  • 作品の中の他人の素材と、著作権その他の権利の侵害。
  • 作品の中の第三者の個人データ。
  • 生成モデルについての申告と、そこに書かれていない使用。
  • 投稿の規程で投稿者が確認する事柄が、すべて真実であること。

モデレーションによって、これらのどれかが運営者に移ることはありません。掲載が示すのは、投稿がモデレーションの規程の確認を通ったことだけです。投稿時に投稿者が確認した事柄が真実でなかったために、第三者が Sophaxis や運営者に請求をした場合、法令の定めるところにより、著者がその責任を負います。著者は、削除の規程に沿って削除の求めを検討するあいだ、記録の頁（題・著者・要旨・PDF の写し）を公開から外すこと、そのあいだ OAI-PMH がその記録を削除済みとして示すことに同意します。様式に書かれた文は、ライセンスの規程が定めるとおりに共有します。運営者は、それでも削除の規程に沿って求めに応じます。

読者ができること

読者は、載っている作品のそれぞれを、その作品自身のライセンスに沿って、読み、ダウンロードし、再利用できます。このサイトの文は、ライセンスの規程が定めるとおり、CC BY 4.0 で再利用できます。

してはいけないこと

  • 自分が著者でない作品を投稿すること。
  • 著作権その他の権利を侵害する素材を投稿すること。
  • 法令上の根拠なく、第三者の個人データを投稿すること。
  • スパム、嫌がらせ、サイトや投稿の手続きを妨げようとすること。

運営者は、これらの決まりに反する投稿を、断り、または削除することがあります。

保証しないこと

Sophaxis は、現状のまま提供します。載っている作品の質・正しさ・完全さを保証しません。サイトにいつでも届くことも保証しません。運営者は、自らの故意または過失で生じさせた損害について、日本の法令の定めるとおり責任を負います。著者が書いた作品の内容だけ、または GitHub・Vercel・預け先だけが原因で生じた損害については、法令が運営者に責任を負わせる場合を除き、運営者は責任を負いません。Sophaxis は、運営者を日本の消費者契約法の事業者であるものとみなして、読者と著者に同法を適用します。

変更と終了

この規約とほかの規程は、変わることがあります。各頁の日付が最後の変更を示し、過去の版は公開のリポジトリに残ります。どの変更によっても、料金は生じません。

著者や読者の権利を奪い、または狭める変更と、義務を加える変更は、効力を持つ前に、変わる中身とその開始日を添えて、トップの頁で告知します。告知は少なくとも 14 日前に行います。ただし、法令や、安全や法的なリスクのような差し迫った問題が、より早い変更を求める場合は、この限りではありません。その場合でも、変更は効力を持つ前に告知します。文をわかりやすくすることや、例を足すことのようなほかの変更は、公開した時点で効力を持ちます。変更が効力を持った後も Sophaxis を使い続けることは、その変更を受け入れることを意味します。受け入れない人は Sophaxis の利用をやめることができ、著者は撤回の規程に沿って自分の作品を撤回できます。

続けるための備え

Sophaxis は一人で運営しており、失うものなく止められるように組んでいます。

  • 判断が遅いことは、休止ではありません。モデレーションには数週間から数か月かかることがあります。休止とは、病気などのために、運営者が Sophaxis の作業をまったくできないときのことです。それが 30 日を超えて続く場合、トップの頁で新しい投稿の受け付けを休止していることを示します。載っている記録は公開したままです。
  • 運営者が行動できない場合を除き、閉鎖は少なくとも 30 日前にトップの頁で告知し、先に新しい投稿の受け付けを止めます。
  • Sophaxis を閉じる場合、運営者は、すべての記録を収めたリポジトリを公開のまま残し、記録を読めるようにします。頁と PDF の写しは、毎週 Internet Archive にも保存しています。
  • コードと記録は、版を出すたびに Zenodo に保存しています。いちばん新しい版を指す DOI は 10.5281/zenodo.24033371 です。
  • 運営者は、Sophaxis をほかの人、機関、または法人に引き継ぐことがあります。引き継ぎは先にサイトで告知し、新しい運営者が通常の手続きで変えるまで、この規約は効力を保ちます。
  • 誰でも、リポジトリを写し、そのライセンスのもとで、ほかの場所で作業を続けられます。文は CC BY 4.0、コードは MIT です。載っている作品は、それぞれ自身のライセンスを保ちます。
  • DOI は、Sophaxis に何があっても、それを発行した預け先に残ります。

準拠法

この規約は、日本法に準拠します。この規約のどの定めも、法令が制限を認めない権利を制限しません。特に、故意または重大な過失による責任や、日本の消費者契約法その他の法令が免除や制限を認めない責任を、免除したり制限したりしません。

紛争

Sophaxis や載っている作品についての紛争は、できるかぎり合意で解決します。

  1. まず運営者に連絡します。運営者の ORCID の記録にあるメールアドレスへ送るか、公開してよい事柄なら issue に書きます。何についての紛争か、何があれば解決するかを書きます。
  2. その後、双方が誠実に話し合い、合意を目指します。運営者は 7 日以内に答え、紛争を返事のないまま放置しません。
  3. 話し合いで 60 日以内に解決しない場合、どちらの側も、裁判の前に、日本の簡易裁判所の民事調停のような調停を申し出ることができます。

これらの方法で解決しない紛争は、様式でこの規約に同意した人との間では、運営者の住所地を管轄する地方裁判所または簡易裁判所を、第一審の合意管轄裁判所とします。この合意は専属的なものではありません。それ以外の人との間では、法令の定める裁判所が管轄します。運営者の住所は、運営者と連絡先の頁にあるとおり、求めがあれば知らせます。これは、消費者や日本国外の人が、法令によって別の裁判所で訴えを起こし、または応じる権利を奪うものではありません。この節のどの定めも、誰かが裁判所に緊急の救済を求めることや、削除の規程を使うことを妨げません。

日本国外の方へ

Sophaxis は日本から運営しており、どこからでも読めます。

  • 同じ手順が適用されます。話し合いと調停は、書面やオンラインで、英語か日本語で行えます。紛争を解決するために、誰も日本へ来る必要はありません。
  • この規約は日本法に準拠します。その人自身の国の法令が、合意で排除できない保護、たとえば消費者の保護を与えている場合、その保護は引き続き適用されます。
  • 日本国外の人が、自国の法令に基づいて自国の裁判所に訴えることができる場合、その権利は残ります。上の裁判所についての合意が、それを奪うことはありません。
  • この規約は英語で書かれており、この日本語の訳を公開しています。訳が英語の文と食い違う場合は、英語の文が適用されます。

GitHub と Vercel

Sophaxis は、米国に拠点を置く二つのサービスの上で動いており、それぞれの規約もこの規約と並んで適用されます。

  • Sophaxis に投稿することは、GitHub を使うことを意味します。issue を開くこと、コメントすること、ファイルを添付することは、利用者と GitHub とのあいだで、GitHub の利用規約とプライバシーステートメントに従います。
  • Sophaxis を読むことは、Vercel から頁を受け取ることを意味します。Vercel は、IP アドレスを含むそれぞれの要求を、自らの規約と個人情報の方針に沿って、日本や読者の国以外の国で処理することがあります。
  • この規約が拘束するのは、運営者と Sophaxis を使う人です。GitHub や Vercel を拘束せず、GitHub や Vercel に対する請求権も、GitHub や Vercel が行ったことについての運営者に対する請求権も、誰にも与えません。
  • GitHub や Vercel そのものとの紛争は、それぞれの準拠法と裁判所の定めを含め、それぞれの規約に従います。上の「紛争」の手順が扱うのは、運営者と Sophaxis だけです。
  • Sophaxis のリポジトリや issue の中の素材は、GitHub 自身の手続きで GitHub に通報することもでき、サイトの素材は Vercel に通報することもできます。運営者は、GitHub や Vercel が対応したかどうかにかかわらず、削除の規程に沿って求めに応じます。
  • GitHub や Vercel が、たとえば米国の法令に基づいて、自らの側で何かを削除し、制限し、または遮断した場合、Sophaxis はそれを元に戻せないことがあります。

一般

  • ほかの規程は、この規約の一部です。ある規程がある事柄をより詳しく扱う場合は、その事柄についてはその規程が適用されます。それ以外で両者が食い違う場合は、この規約が適用されます。FAQ、手順を順に示す頁、免責事項は、この規約を説明するもので、この規約を変えるものではありません。
  • この規約の一部が無効または執行できないとされた場合も、残りは効力を保ち、その部分は法令が許す範囲で適用されます。
  • 運営者がある時点でこの規約の一部を執行しなくても、それによってその部分を放棄したことにはなりません。
  • 2026-11-21 から、13 歳未満の人は投稿できません。
  • 18 歳未満の人は、親または保護者の同意がある場合に限り投稿できます。
  • 未成年として投稿した人に、法令が掲載の削除を求める権利を与えている場合は、削除の規程が適用されます。
  • 運営者への通知は、ORCID の記録にあるメールアドレスへのメールか、issue で行います。著者への通知は、その著者の投稿の issue で行います。

連絡先

運営者と、運営者に連絡するすべての方法は、運営者と連絡先の頁にあります。質問はリポジトリの issue へどうぞ。公開すべきでない事柄は、運営者の ORCID の記録にあるメールアドレスへメールで送ります。素材の削除の求めは、削除の規程に沿って行います。
