預け先と DOI 登録機関へ（日本語訳）

最終更新：2026-11-23。

これは英語の For repositories and DOI registration agencies の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。

この頁は、Sophaxis が載せている作品の預け先と、その DOI を登録する機関に宛てたものです。Sophaxis がそれぞれのサービスから何を読むか、どのくらいの頻度で読むか、読んだものをどう使うかを書きます。

載せている預け先

2026-12-07 から、新しい作品は、次の 3 つの預け先からだけ受け付けます。

  • SSRN：10.2139/ssrn. で始まる DOI
  • arXiv：10.48550/arXiv. で始まる DOI
  • Jxiv：10.51094/jxiv. で始まる DOI

2026-12-06 までは、次の 12 の預け先の新しい作品も受け付けます。2026-12-07 より前に issue を開いた投稿は、合わせて 15 の預け先で判断します。

  • Zenodo：10.5281/zenodo. で始まる DOI
  • Figshare：10.6084/m9.figshare. で始まる DOI
  • OSF Preprints：10.31219/osf.io/ で始まる DOI
  • SocArXiv：10.31235/osf.io/ で始まる DOI
  • MetaArXiv：10.31222/osf.io/ で始まる DOI
  • Preprints.org：10.20944/preprints で始まる DOI
  • Research Square：10.21203/rs.3.rs- で始まる DOI
  • SciELO Preprints：10.1590/SciELOPreprints. で始まる DOI
  • Qeios：10.32388/ で始まる DOI
  • ScienceOpen Preprints：10.14293/PR2199. で始まる DOI
  • Advance：10.31124/advance. で始まる DOI
  • KC Works：10.17613/ で始まる DOI

すでに載っている作品は載ったままで、その新しい版は、作品が載っている預け先から受け付けます。いま載っている記録のうち、これらの預け先にあるのは、Zenodo に 2 件です。

作品を載せるのは、その著者が投稿したときだけです。DOI のメタデータに CC BY 4.0、CC BY-SA 4.0、CC0 1.0 のどれかが記されていることも要ります。Sophaxis は、どの預け先からも収集やミラーをしません。

Sophaxis が読むもの

  • 投稿された作品の DOI のメタデータ。DataCite と Crossref の公開の REST API から読み、Jxiv の作品は JaLC から読みます。作品が投稿されたときと、その issue が編集されたときに一度読みます。載っている DOI はそれぞれ週に一度読み、まだ解決し、ライセンスを保っていることを確かめます。DataCite 自身の文が、API のこの使い方を認めています。REST API の案内は「Members and non-members wishing to harvest DataCite metadata should use the Public API, which does not require authentication.」と書き、データファイルの利用の方針は「Consistent with this broad waiver, DataCite does not impose any conditions on access to and use of the DataCite Data File.」「The DataCite Data File is available via the DataCite APIs and the annual public Data File.」と書きます。これらの頁は、DataCite のウェブサイトのほかの頁と同じく、Internet Archive の写しから読みました（2026-11-15 に取り寄せ）。
  • 作品の版の一覧。同じメタデータから読みます。
  • 版の PDF。手を加えずに取ります。取るのは、作品のライセンスが許し、預け先が自らの頁でスクリプトによる取得を認めている場合だけです（Zenodo）。Zenodo の REST API を通します。この変更を公開した 2026-11-13 までは、Figshare と Research Square からも取っていました。公開してからは取りません。どちらの規約もロボットとスクリプトを禁じており、著作権の規程がその文を引いています。2026-11-15 からは、arXiv からもスクリプトで何も読みません。arXiv へのリンクは残します。写しは版ごとに一度、運営者が手で始めたときに取ります。投稿の issue が開かれたときと編集されたときにも、確認の手順が最新の版の PDF を取ります。モデレーターのために形を読むためだけで、読んだあとは消します。預け先がチェックサムを公開している場合、写しはそれと一致しなければなりません。

Sophaxis 自身のコードが出す要求は、どれも User-Agent に Sophaxis とそのリポジトリを書きます。Sophaxis (https://github.com/cpsbvbng26-dotcom/sophaxis) です。投稿の確認の助言の段階は deposit-check を走らせ、deposit-check は自分の名を書きます。deposit-check (https://github.com/cpsbvbng26-dotcom/deposit-check) です。Sophaxis は、人が読むための頁を読みません。どんな上限も遮断も、すり抜けません。

Sophaxis が示すもの

それぞれの記録の頁は、DOI へリンクし、預け先の名を挙げます。読者には、その DOI を引用するよう求めます。引用の先は DOI のままです。Sophaxis は、自分の DOI を与えません。要旨と PDF の写しは、著作権の規程が定めるとおり、作品自身のライセンスのもとで、著者とともに示します。

何かを変えるべきとき

Sophaxis の読む頻度が許す範囲を超えているとき、規約が許さないものを読んでいるとき、サービスからファイルを写すのをやめるべきときは、運営者に知らせてください。Sophaxis は、それを変えるか、やめます。預けたものそのものについての求めは、預け先が扱います。Sophaxis は、預けたものを変えることも削除することもできません。

運営者には、issue か、運営者の ORCID の記録にあるアドレスへのメールで連絡できます。

預け先と登録機関に対する免責

Sophaxis は独立しています。どの預け先とも、どの登録機関とも、組織のうえのつながりはなく、後ろ盾も受けておらず、協力関係にもありません。エルゼビア、コーネル大学、JST（科学技術振興機構）とも同じです。運営者は、投稿の規程で、この三つを信頼できる機関・出版社と定めていますが、それは運営者自身の定めで、ほかの預け先の評価ではありません。Sophaxis は、載せている作品の Zenodo の記録のために、Zenodo にコミュニティ（<https://zenodo.org/communities/sophaxis>）を置いています。2026-12-07 からは、Zenodo にだけ預けた新しい作品は Sophaxis が受け付けないので、その記録を足す依頼は断ります。すでに載っている作品と、Zenodo にあるその新しい版の記録は、これからも足せます。コミュニティは、Zenodo の利用者ならだれでも開けます。これによって Sophaxis が Zenodo の一部になるわけではありません。Sophaxis の記録は、預けたものについての Sophaxis 自身の説明です。預け先や登録機関が述べたものではありません。それらは、Sophaxis にも、その記録にも、そのモデレーションにも、それらのメタデータを示すときに Sophaxis が持ち込んだ誤りにも、責任を負いません。それらの名は、それぞれのサービスを示すためだけに使っています。商標はそれぞれの持ち主に属し、Sophaxis はどのロゴも示しません。Sophaxis は、それぞれのサービスを公開の口を通して使い、公表された規約の範囲で使います。規約の範囲は、Sophaxis が理解しているとおりです。サービスが違うことを述べるときは、Sophaxis はサービスに従います。免責事項も見てください。

謝辞

Sophaxis があるのは、これらのサービスが研究とそのメタデータを開かれた形で示しているからです。Sophaxis は、次のサービスに感謝します。

  • SSRN, for keeping the deposits and their DOIs
  • arXiv, for keeping the deposits and their DOIs
  • Jxiv, for keeping the deposits and their DOIs
  • Zenodo, for keeping the deposits and their DOIs
  • DataCite, for DOI metadata, openly available under CC0
  • Crossref, for DOI metadata, openly available through its REST API
  • Japan Link Center (JaLC), for DOI metadata for Jxiv
  • ORCID, for public records through its public API, for the identity check
  • the Internet Archive, for saved copies of the pages and the PDF copies
  • GitHub, for the repository, the submissions and the automatic checks
  • Vercel, for serving the site

Thank you to arXiv for use of its open access interoperability. arXiv のオープンアクセスの相互運用性を使えることに、arXiv に感謝します。
