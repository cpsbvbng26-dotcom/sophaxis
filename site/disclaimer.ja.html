載っている作品

掲載はモデレーションであって、査読ではありません。Sophaxis は証明・論証・データを確かめず、載っている作品が正しいこと、独創的であること、完全であること、何らかの質を持つことを保証しません。著者は、生成モデルについての申告を含め、自分の作品にすべての責任を負います。Sophaxis はその申告を検証しません。

メタデータ

題・著者・要旨・ライセンス・版・日付は、DataCite、Crossref、JaLC が保持する DOI のメタデータから取り、受け取ったとおりに示します。メタデータに要旨がない場合は、投稿の様式に書かれた要旨を示します。そこに誤りがあれば、ここにも出ることがあります。誤りは、記録の頁のそれぞれにあるリンクから報告できます。

本人の確認

自動の確認は、ORCID の記録を管理している人が投稿の issue を開いたこと、その ORCID iD が作品の著者のものであることを確かめます。公的な本人確認ではありません。

提携していないこと

Sophaxis は、独立した個人のプロジェクトです。載せている作品の預け先のどれとも、DataCite、Crossref、JaLC、OpenAlex、ORCID、GitHub、Vercel、Internet Archive のどれとも、提携しておらず、推薦も受けておらず、協力関係にもありません。それらの名は、それぞれのサービスを示すためだけに使っており、それぞれの持ち主に属します。それらは、Sophaxis にも、その記録にも、Sophaxis が持ち込んだ誤りにも、責任を負いません。預け先と DOI 登録機関への頁も見てください。

誰が、なぜ Sophaxis を運営するか

いまは唯一のモデレーターでもある運営者が、無報酬のボランティアとして Sophaxis を運営しています。Sophaxis の仕事で報酬を受ける人はおらず、投稿にも閲覧にも料金は要りません。Sophaxis は、GitHub と Vercel の無料のサービスの範囲だけで、sophaxis.vercel.app のアドレスで配信しており、支払うべきドメインやホスティングはありません。運営者は、サイトとそのコードを書く道具である Claude Code の料金を、個人で払っています（下の「Sophaxis の作り方」を見てください）。Sophaxis は、その費用に充てるお金を誰からも受け取りません。無報酬で務めていても、利用規約と個人情報の取り扱いについてのもとで運営者が読者と著者に負う務めは軽くなりません。

Sophaxis を始めたのは、運営者が、哲学と数学の公開のプレプリントを並べて載せる場所を一つ探して、見つからなかったからです。次の節が述べるとおり、運営者自身が読むために、そして同じ問いに取り組む人のために置いています。これは運営者の理由であって、ほかのアーカイブへの評価ではありません。Sophaxis はそれらに代わるものではなく、ここに載る作品は、それぞれの預け先に置かれたままです。

運営者自身の使い方

運営者は、個人の本棚の延長として、趣味で Sophaxis を置いています。哲学と数学の作品を手元に置き、読むための場所です。この使い方によって、何を載せるか、どう載せるかは変わりません。

  • 作品を投稿できるのは、その作品の著者だけです。運営者は、読んだから、手元に置きたいからといって、他人の作品を載せません。そのような作品は、Sophaxis の外の、運営者自身の本棚に置きます。
  • Sophaxis は営利のために運営していません。誰からも料金を取らず、何も売らず、広告を出さず、何の収入も得ません。
  • Sophaxis は作品を出版しません。それぞれの作品は、その預け先が DOI のもとで公開し、Sophaxis はそこへリンクします。
  • PDF の写しは、著者が預けたファイルを手を加えずに置いたもので、作品のライセンスが認める範囲でだけ、著者、ライセンス、原本へのリンクを添えて共有します。著作権の規程を見てください。
  • Sophaxis は、どの作品についても、著作権も独占的な許諾も取りません。
  • 権利者は、削除の規程に沿って作品の削除を求めることができます。

これらの決めによって、Sophaxis は、著者とライセンスが認める範囲に収まるようにしています。これらは法的な助言ではなく、法的な問題が一つも起こりえないと主張するものでもありません。

GitHub とその他のサービス

Sophaxis は GitHub の上で動いています。コード、記録、投稿（GitHub の issue）はそこに保管し、自動の確認は公開のリポジトリの GitHub Actions として動きます。サイトはそのリポジトリから組み立て、Vercel が配信します。Sophaxis は GitHub や ORCID でのサインインを使わず、誰にもアカウントへのアクセスを求めません。DataCite、Crossref、JaLC、OpenAlex、ORCID、預け先の公開の API を通して、公開のデータだけを読みます。投稿のために GitHub を使うことには、GitHub 自身の規約とプライバシーステートメントが適用されます。

利用できること

サイトは現状のまま提供し、利用できなくなったり、変わったり、閉じたりすることがあります。閉じた場合も、すべての記録を収めたリポジトリは公開のまま残ります。利用規約の「続けるための備え」を見てください。

Sophaxis は、外部のサービスに頼っています。

  • Vercel が止まれば、サイトは配信されません。記録は GitHub のリポジトリと Internet Archive に残ります。
  • GitHub が止まれば、誰も投稿できず、自動の確認も動きません。サイトは、最後に組み立てたものを示し続けます。
  • DataCite、Crossref、JaLC に届かなければ、届くようになるまで投稿を確かめられません。
  • 預け先が預けたものを削除すれば、その DOI は解決しなくなり、記録は撤回の規程に沿って撤回します。
