Sophaxis は GitHub の上で動いています。コード、記録、投稿（GitHub の issue）はそこに保管し、自動の確認は公開のリポジトリの GitHub Actions として動きます。サイトはそのリポジトリから組み立て、Vercel が配信します。Sophaxis は GitHub や ORCID でのサインインを使わず、誰にもアカウントへのアクセスを求めません。DataCite、Crossref、JaLC、OpenAlex、ORCID、預け先の公開の API を通して、公開のデータだけを読みます。投稿のために GitHub を使うことには、GitHub 自身の規約とプライバシーステートメントが適用されます。GitHub と Vercel は、それぞれ自らの規約で、サービスを「現状のまま」保証なしに提供し、責任を限っています。Sophaxis は、二つのサービスについて、それぞれが約束する以上のことを約束できません。サイトは Vercel の無料の Hobby プランで配信しており、Vercel はこのプランの配信を、予告の有無を問わず止めたり削除したりできます。二つの規約の定めは、利用規約の「GitHub と Vercel」にあります。

利用できること

サイトは現状のまま提供し、利用できなくなったり、変わったり、閉じたりすることがあります。閉じた場合も、すべての記録を収めたリポジトリは公開のまま残ります。利用規約の「続けるための備え」を見てください。

Sophaxis は、外部のサービスに頼っています。

  • Vercel が止まれば、サイトは配信されません。記録は GitHub のリポジトリと Internet Archive に残ります。
  • GitHub が止まれば、誰も投稿できず、自動の確認も動きません。サイトは、最後に組み立てたものを示し続けます。
  • GitHub の規約は、GitHub が GitHub Actions の利用を制限することを認めています。Actions が止まることもあります。動かないあいだは、自動で動く手順の頁の手順は、どれもひとりでには動きません。運営者ができしだい手で行います。個人データの露出が報告された記録の頁も、運営者が手で外し、すぐには外れません。
  • DataCite、Crossref、JaLC に届かなければ、届くようになるまで投稿を確かめられません。
  • 預け先が預けたものを削除すれば、その DOI は解決しなくなり、記録は撤回の規程に沿って撤回します。
