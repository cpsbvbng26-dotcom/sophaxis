Sophaxis とは何ですか？

哲学・数学・論理学・数理哲学・科学哲学のための、オーバーレイ型のプレプリントサーバーです。作品そのものは、その預け先が公開します。Sophaxis は、ライセンスが許す場合にだけ、手を加えていない PDF の写しを置きます。著者がすでに公開の預け先に預けたプレプリントを載せ、それぞれに変わらない記録の頁を与えます。

査読ですか？

いいえ。受理はモデレーションであって、査読ではありません。モデレーションが確かめるのは、投稿者、ライセンス、対象の分野、論文の形、生成モデルについての申告です。証明・論証・データは確かめません。Sophaxis は、載っているどの作品の質も保証しません。モデレーションの規程を見てください。

費用はかかりますか？

いいえ。Sophaxis は、著者からも読者からも料金を取りません。これから取り始めることもありません。

Sophaxis は作品に DOI を与えますか？

いいえ。DOI は作品を預けた預け先が与えるもので、引用するのはその DOI です。Sophaxis は、それぞれの記録に 2026.0001 のような番号を与えます。この番号は変わらず、ほかの記録に使い回すこともありません。

どの預け先を受け付けますか？

Zenodo、Figshare、OSF Preprints、SocArXiv、MetaArXiv、arXiv、Preprints.org、SSRN、Research Square、SciELO Preprints、Qeios、ScienceOpen Preprints、Advance、KC Works、Jxiv です。作品は、そのどれかから DOI を得ている必要があります。

どのライセンスを受け付けますか？

DOI のメタデータに記された CC BY 4.0、CC BY-SA 4.0、CC0 1.0 です。非営利（NonCommercial）や改変禁止（NoDerivatives）の条件を持つライセンスは受け付けません。arXiv の非独占的ライセンスも受け付けません。ライセンスの規程を見てください。

誰が投稿できますか？

ORCID iD を持つ、作品の著者だけです。ORCID の記録が GitHub のアカウントにリンクしている必要があります。その ORCID iD が作品の著者のものであることは、自動の確認が確かめます。著者全員が、掲載に同意している必要があります。投稿の規程を見てください。

なぜ GitHub なのですか？

投稿は GitHub の issue です。こうすると、すべての段階が公開されます。自動の確認も、issue を開いたアカウントが著者のものであることを確かめられます。Sophaxis は、自前のアカウントもパスワードも持ちません。

Sophaxis は GitHub や ORCID とつながっていますか？

はい。ただし、公開の範囲でだけです。コード、記録、投稿は GitHub にあり、自動の確認は公開のリポジトリの GitHub Actions として動きます。ORCID は、その公開の API を通して読みます。Sophaxis は GitHub や ORCID でのサインインを使わず、誰にもアカウントへのアクセスを求めません。どちらとも、組織としての関係はありません。免責事項を見てください。

Sophaxis は言語モデルで作られましたか？

はい。サイト、そのコード、規程は、運営者の求めにより、Claude Code（Anthropic）で書きました。運営者がそれらに責任を負います。Claude は著者ではありません。投稿について判断する言語モデルはありません。免責事項を見てください。

言語モデルを使ってもよいですか？

はい。どう使ったかを申告すれば使えます。使った道具の名を挙げ、何に使ったかを書きます。これは、画像やコードを作るものを含め、すべての生成モデルに当てはまります。生成モデルは著者になれません。申告は記録の頁に示します。

モデレーションにはどれくらいかかりますか？

目安として、判断は投稿の当日に出ることもありますが、数週間から数か月かかることもあります。判断が遅くても、投稿の受け付けを止めているわけではありません。止めているときは、トップの頁がそう示します。投稿から掲載までの頁が、一つの投稿を順にたどります。

載っている作品に責任を負うのは誰ですか？

作品とその掲載には、著者がすべての責任を負います。内容、共有する権利、他人の素材、作品の中の個人データ、生成モデルについての申告です。利用規約を見てください。

新しい版はどう加えますか？

預け先に預けてから、更新として投稿し、既存の Sophaxis の番号を書きます。前の版も載ったままです。

作品が学術誌で出版されました。投稿できますか？

受け付けるライセンスで共有してよい版に限ります。様式に出版された版の DOI を書くと、記録がそれを示します。

載っているプレプリントが出版されました。どうすればよいですか？

著者の一人として、出版された版の様式で報告します。プレプリントは載ったままです。記録の頁は出版された版を先頭に示し、読者にそれを引用するよう求めます。Sophaxis は査読を評価しません。記録は、査読について著者が述べたことをそのまま示します。詳しくは、投稿の規程の「作品が出版されたとき」にあります。

Sophaxis は PDF の写しを置きますか？

預け先がスクリプトによる取得を許す場合、Sophaxis は手を加えていない写しを置きます。検索エンジンが全文を索引に入れられるようにするためです。ほかの預け先の場合は、預けた PDF を投稿の issue に添付できます。写しを置くのは、ファイルが 20 MB までのときだけです。著作権の規程を見てください。

作品は Google Scholar に出ますか？

それぞれの記録の頁は、Google Scholar が読むタグを持っています。サイトマップは、すべての頁を挙げています。Scholar は記録の頁と同じディレクトリにある PDF だけを取るので、PDF の写しもそれぞれそこから配信しています。記録の頁や PDF の写しが新しくなったり、変わったり、外されたりしたときは、公開されしだい、Bing のような IndexNow を受け付ける検索エンジンに知らせます。新しい頁や変わった頁は、著者全員が同意していれば、Internet Archive にも保存します。Google は、代わりにサイトマップを読みます。Sophaxis は、検索エンジンが頁を索引に入れることを約束できません。

投稿の前に何を確かめればよいですか？

確かめることの頁が、規程が求めることを、生成モデルについての申告の例とともに集めています。論文の雛形も二つ（Markdown と LaTeX）、CC0 1.0 で置いています。使う決まりはありません。

Sophaxis は読者を追跡しますか？

しません。個人情報の取り扱いについてのとおり、サイトは cookie を使わず、アクセス解析をせず、ほかのサーバーから何も読み込みません。閲覧やダウンロードの数も示しません。

メールでの配信はありますか？

ありません。Sophaxis はニュースレターを送らず、そのためのメールアドレスも集めません。新しい記録とお知らせは、Atom の配信で追えます。新しいプレプリント、お知らせ、それに分野ごとの配信があります。

ここに載っている作品はどう引用しますか？

読んだ版の DOI を引用します。それぞれの記録の頁は、APA、Chicago、BibTeX の形の引用と、BibTeX、RIS、CSL-JSON のファイルを示します。

記録の誤りはどう報告しますか？

記録の頁にある「Report an error in this record」のリンクを使います。訂正は、日付付きの注記として記録に加えます。

作品を撤回できますか？

はい。著者なら誰でも一人で、載っている作品を撤回できます。引用が切れないよう、記録の頁は撤回の告知とともに残ります。PDF の写しは、サイトから外します。撤回の規程を見てください。

素材の削除はどう求めますか？

著作権の侵害、個人データの露出、その他の法的な理由がある場合は、削除の規程に従います。

Sophaxis が閉じたら、記録はどうなりますか？

すべての記録を収めたリポジトリは、公開のまま残ります。記録は読めるままです。Sophaxis は毎週、著者全員が同意した作品について、頁と PDF の写しを保存するよう、Internet Archive に頼んでもいます。

誰が Sophaxis を運営していて、運営者にはどう連絡しますか？

運営者と連絡先の頁を見てください。
