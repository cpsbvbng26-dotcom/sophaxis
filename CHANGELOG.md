# Changelog

The notable changes to Sophaxis, newest first. Each entry names the pull request that made it.
The entries are grouped by the date of the merge. Version 1.0.0 was released on 2026-11-07 and archived at Zenodo (10.5281/zenodo.24033372; every version: 10.5281/zenodo.24033371). Version 1.1.0 is dated 2026-11-12 and gathers every change merged since 1.0.0, those of 2026-11-12 included. The operator stopped its release on 2026-11-12: no GitHub Release and no Zenodo version of 1.1.0 exist, and no Zenodo DOI of its own is recorded.
