# 個人情報の取り扱いについて

最終更新：2026-11-12。

Sophaxis の個人情報の取り扱いを、日本の個人情報保護法の項目に沿って書いたものです。英語の [Privacy Policy](./privacy.md) の訳で、項目を日本の個人情報保護法に沿って並べ替えてあります。英語と違うところは、英語が優先します。

この頁が引く法令・ライセンス・規約の文は、引いている節の終わりに置いています。
日本の法令は、e-Gov 法令 API が示す条文を全文で引いています。ほかの文は、公式の出どころから 2026-11-12 に取り寄せた文を、語のまま引いています。訳は付けていません。
原文を取り寄せられなかった条は、引いていないことと、その理由を記しています。

## 取り扱う者

Sophaxis の運営者、根本卓哉です。住所は公開していません。求めがあれば、遅滞なく知らせます。
運営者が個人情報保護法の「個人情報取扱事業者」に当たるものとして、同法の定めをすべて守ります。

## 取り扱う個人情報

- 投稿の issue に載る GitHub のユーザー名と、投稿の様式に書かれた内容
- 載せた論文の著者の氏名と ORCID iD（DOI の登録情報から取ります）
- 本人確認のために読む、ORCID の公開記録のうち、氏名・ウェブサイト・業績
- 撤回や出版版の報告の様式に書かれた内容
- 2026-11-21 から、共著者が同意を確かめるコメントに書く GitHub のユーザー名と ORCID iD
- 2026-11-23 から、初めての投稿を紹介する研究者がコメントに書く GitHub のユーザー名と ORCID iD。その ORCID の公開記録のうち、氏名・ウェブサイト・業績も同じように読みます。これらはその研究者自身の行為で issue に公開されます

本人確認では、ORCID に、公開記録のうち「個人の詳細」（氏名）・「ウェブサイト」・「業績」の部分だけを問い合わせます。
「人物」の部分をまとめて問い合わせないので、公開のメールアドレスや国を受け取ることはありません。
検査が使うのは氏名・ウェブサイト・業績だけで、ほかは保存せず、どこにも書き写しません。
サイトは、閲覧者の個人情報を集めません。Cookie も、アクセス解析も使いません。
頁には、閲覧者の情報を外へ送るコードもタグもありません。
電気通信事業法の外部送信の規律（第 27 条の 12）が掛かるのは、電気通信事業者と、登録も届出も要らないとされる電気通信事業を営む者だけです。そのうちでも、総務省令が定める役務に限られます。役務を使うのに要る情報は、この規律から除かれています。
Sophaxis は何にも料金を取らず、サイトから何の収益も得ていません。そのため運営者は、電気通信事業を営んでいないと考えており、第 27 条の 12 は Sophaxis に掛からないと考えています。
掛かるとしても、頁が出す要求は、検索の頁が Sophaxis 自身のサイトに記録の一覧を求めるものだけで、それはその頁を使うのに要るものです。
総務省令は取り寄せていません。この考えは、法律の条文と、総務省の電気通信事業参入マニュアルに拠っています。
検索の頁は、Sophaxis 自身が配るスクリプトを一つだけ動かします。Sophaxis から記録の一覧を読み、閲覧者のブラウザの中で検索し、どこにも何も送りません。ほかの頁はスクリプトを動かしません。
記録の頁には、X・Bluesky・Facebook・LinkedIn・メールへの共有のリンクがあります。どれも各サービスの頁への普通のリンクで、閲覧者がたどるまで何も送られず、たどった先では各サービスの方針が掛かります。
Sophaxis は、Vercel のアクセス解析を有効にしていません。
記録の頁を含め、どの頁も、閲覧やダウンロードの数を示しません。Sophaxis はその数を持ちません。数を作るアクセス解析を動かさず、Vercel の閲覧の要求の記録から読者を数えることもしません。

投稿・撤回・出版版の報告には、ORCID iD と、その ORCID の記録がリンクする GitHub のアカウントが要ります。
これが無いと検査は著者を確かめられず、issue では手続きを進められません。
その場合も、各規程のとおりメールで求めることができます。
ほかには何も求めません。

## 利用目的

- 投稿者が、その論文の著者本人であることを確かめるため
- 2026-11-21 から、同意を確かめる共著者が、その論文の著者本人であることを確かめるため
- 2026-11-23 から、初めての投稿を紹介する研究者が、その論文の著者でなく、学術誌の論文・本の章・本を持つことを確かめるため
- 撤回や出版版の報告をする人が、その論文の著者本人であることを確かめるため
- 論文の記録の頁、著者ごとの頁、一覧と検索を作り、公開するため
- 記録を `feed.xml`・`papers.json`・OAI-PMH（`/oai`）で再利用できる形にするため
- 毎週、DOI とライセンスを確かめるため。著者が同意した作品については、頁と PDF の写しを Internet Archive に保存するため（頁が変わったときにも保存します）
- 新しく載った頁、変わった頁、削除した頁の場所を、検索エンジンに知らせるため
- 撤回・訂正・削除の求めと、個人情報についての求めに応えるため
- サイトを配信し、Vercel の閲覧の要求の記録から不具合を見つけて直すため
- 問い合わせ・苦情・紛争・安全についての報告に応えるため

ほかの目的には使いません。

## 公開と第三者への提供

著者の氏名と ORCID iD は、記録の頁で公開します。
記録は、`feed.xml`・`papers.json`・OAI-PMH でも公開します。OpenAIRE などの収集者は、そこから題・著者・要旨・ライセンスを写します。
著者が同意した作品の頁と PDF の写しは、Internet Archive（米国）に保存します。
Zenodo に置かれた作品は、Zenodo にある Sophaxis のコミュニティ（https://zenodo.org/communities/sophaxis）にも集めることがあります。
コミュニティに記録を出すのは著者です。記録を持つのは Zenodo で、運営はスイスの CERN です。
Sophaxis はコミュニティから何も写しません。運営者がそこの記録を書き換えることもありません。
2026-11-22 から、著者のだれかが Sophaxis を提供しない国と地域（投稿の規程の表にあります）に住んでいるか、投稿から掲載までのあいだにそこに滞在した作品については、記録を足す依頼を断ります。その作品は Sophaxis に載らないためです。依頼そのものは、CERN の規約のもとで Zenodo に残ります。
投稿の様式で、すべての著者が掲載と、下の「外国にある事業者の利用」に挙げる提供に同意していることを確かめます。Internet Archive への保存は別の同意で、空けておくこともできます。
法令に基づく場合を除き、これ以外に個人情報を第三者へ渡すことはありません。
ほかの者がすでに写したものは、Sophaxis の手の外にあります。

## 外国にある事業者の利用

Sophaxis は、外国にある次の事業者のサービスを使います。
記録に含まれる個人データが GitHub・Vercel・ORCID・Internet Archive に渡ることと、審査のあいだ投稿の公開されている部分が Anthropic・OpenAI・xAI に渡ることを、個人情報保護法第 28 条の「外国にある第三者への提供」として扱います。
投稿の様式で、この頁の情報を示したうえで、著者それぞれの同意を求めます。この確認は 2026-11-21 から必須です。
それまでは、運営者以外の著者の作品は、すべての著者が投稿の issue でこの同意を示してから載せます。
Internet Archive への保存の同意は、別の欄で尋ねます。空けておくこともでき、そのときは記録をそこに保存せず、`robots.txt` で Internet Archive に集めないよう求めます。
どの著者も、どちらの同意も、削除の issue かメールでいつでも撤回できます。撤回の前に行ったことは、適法なままです。
Internet Archive への同意を撤回すると、著者からの求めであることを運営者が確かめたうえで、審査なしに保存をやめます。運営者は、それまでの写しを除くよう Internet Archive に頼みます。
GitHub・Vercel・ORCID への提供の同意を撤回すると、記録を削除します。これらが無いと作品を載せられないためです。

- GitHub（米国）：投稿の受け付けと、記録の保管
- Vercel（米国）：サイトの配信。閲覧の要求を、IP アドレスを含めて処理します
- DataCite（ドイツ）・Crossref（米国）：DOI の登録情報を読むため
- ORCID（米国）：ORCID の公開記録を読むため
- Internet Archive（米国）：公開した頁と PDF の写しを保存するため
- OpenAlex（米国）：載せた作品をどう収めているかを、DOI だけで問い合わせるため。人については問い合わせません
- Anthropic・OpenAI・xAI（いずれも米国）：審査を助けるため。運営者が、投稿の公開されている部分（issue、DOI の登録情報、要旨）を、それぞれの言語モデル Claude・ChatGPT・Grok に手で読ませます。掲載の後には渡しません

それぞれの事業者の個人情報の扱いは、各社の規約によります。
米国の制度については、個人情報保護委員会が[米国の制度についての情報](https://www.ppc.go.jp/enforcement/infoprovision/laws/offshore_report_america/)を公表しており、Sophaxis はこれに拠ります。2021 年 10 月の調査に基づく情報です。
委員会は、連邦について「包括的な法令は存在しない。」とし、個別の分野に適用される法令として、電子通信プライバシー法、金融機関についてのグラム・リーチ・ブライリー法、健康情報についての HIPAA を挙げています。
EU の十分性認定はありません。APEC の CBPR システムには、2012 年 7 月 25 日から参加しています。
委員会は、CBPR システムに参加している国では、APEC のプライバシーフレームワークに沿った法令とそれを執行する機関があると考えられ、民間部門について「個人情報の保護について概ね我が国と同等の保護が期待できる」と説明しています。
個人情報の域内保存義務に係る制度と、事業者に政府の情報収集活動への協力義務を課す制度は、委員会の頁ではどちらも挙げられていません。
州の法律もあります。委員会の頁は、カリフォルニア州消費者プライバシー法を包括的な法令として挙げ、イリノイ州とニューヨーク州の法令も報告しています。
各社の頁にある住所では、GitHub・Vercel・Anthropic はカリフォルニア州に、ORCID はメリーランド州にあります。
ドイツは欧州連合の国で、一般データ保護規則（GDPR）が適用されます。
各国の個人情報の保護の制度については、個人情報保護委員会が情報を公表しています。

各事業者が個人情報を守るために講じている措置は、それぞれの方針にあります。

- GitHub：[GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。EU-米国データプライバシーフレームワークに従うと述べています。
- Vercel：[Vercel Privacy Notice](https://vercel.com/legal/privacy-notice)。EU-米国データプライバシーフレームワークに従うと述べています。
- ORCID：[ORCID Privacy Policy](https://info.orcid.org/privacy-policy/)。毎年、EU-米国データプライバシーフレームワークの基準で評価を受けていると述べています。
- Crossref：[Crossref privacy](https://www.crossref.org/operations-and-sustainability/privacy/)
- Internet Archive：[Terms of Use](https://archive.org/about/terms)。受け取るのは公開の頁と PDF の写しだけで、記録がすでに公開している以上の個人データは含みません。Internet Archive が個人情報を守るために講じている措置については、情報を示すことができません。その規約はスクリプトを動かさないと読めず、ほかにその措置を述べたものも見つからなかったためです。
- Anthropic：プライバシーポリシーで、個人データを紛失・誤用・不正なアクセス・開示・改変・破壊から守るための、適切な技術的・組織的な安全管理措置を講じていると述べています。
- OpenAI：OpenAI が個人情報を守るために講じている措置については、情報を示すことができません。そのプライバシーポリシーは、2026-11-12 の自動の取り寄せに、JavaScript と cookie を求める頁を返しました。ほかにその措置を述べたものも取り寄せていません。
- xAI：[Privacy Policy](https://x.ai/legal/privacy-policy)。いまは SpaceX Super Intelligence LLC のプライバシーポリシーです。この会社が個人情報を守るために講じている措置については、情報を示すことができません。2026-11-12 に取り寄せた方針は、データの使い方と渡し先を述べていますが、安全管理の措置を述べていないためです。

GitHub・Vercel・ORCID について、欧州連合からの移転は、各社がその枠組みの認証を受けている限りで、EU-米国データプライバシーフレームワークについての欧州委員会の十分性認定に基づきます。

GitHub と Vercel が自ら記録を使う場合が二つあり、それぞれの規約に定めがあります。Sophaxis はこれを変えられません。

- GitHub の利用規約は、issue と公開のリポジトリに置かれたもの（記録を含みます）を、GitHub とその関連会社が、AI の機能と関連会社のモデルの学習に使うことを認めています（D.4）。公開の内容について、これを止める設定はありません（J.3）。
- Vercel の利用規約は、Sophaxis を配信している無料の Hobby プランでは、サイトの内容（記録を含みます）を、Vercel が AI と機械学習のモデルの学習に使い、そのために第三者に渡すことを認めています。アカウントのチームの設定でこれを止めたときは別です（第 3 条）。Sophaxis のアカウントで、この設定を切ったことは確かめていません。

これらの利用で個人情報が心配な方は、投稿しないでください。著者として載ることにも同意しないでください。Sophaxis は、GitHub と Vercel なしには作品を載せられないためです。載っている作品の著者は、いつでも同意を撤回でき、そのときは記録を削除します（上のとおり）。

メールでの求めは、Apple のメールの受信箱（iCloud メール、米国）に届きます。
応えることと、応えたことを示すのに要る間だけ、そこに置きます。
運営者が住む日本の利用者について、[iCloud 利用規約](https://www.apple.com/jp/legal/internet-services/icloud/jp/terms.html)は、iCloud を提供する Apple の会社を、106-6140東京都港区六本木6丁目10番1号 六本木ヒルズに所在するiTunes株式会社としています。
iCloud 利用規約は、法律に従うため、規約を執行するため、セキュリティ・不正・技術上の問題に対処するためなどに、Apple がアカウントのコンテンツにアクセスし、利用し、保全し、開示できると定めています。そのため iCloud は、メールに含まれる個人データを取り扱います。
個人情報保護委員会の Q&A 7-53 の読み方では、そこに置くことは個人データの提供に当たります。Sophaxis は、iTunes 株式会社をその取り扱いの委託先として扱い（個人情報保護法第 27 条第 5 項第一号）、同法第 25 条により監督します。
iTunes 株式会社は日本の会社です。委員会のガイドライン（外国にある第三者への提供編）は、第三者に当たるかを法人格で判断します。そのため受信箱は、個人情報保護法第 28 条の外国にある第三者への提供には当たらず、メールを書く人に同意は求めません。
Apple は、個人データを、それを管理する Apple の会社に代わって、Apple Inc. やほかの Apple の会社が処理することがあると述べています。Apple Inc. は米国にあります。
委託先が外国で取り扱わせる場合について委員会の Q&A 10-24 が求めるとおり、Sophaxis は、上に示した米国の制度を踏まえて安全のための措置を講じ、「安全のための措置」の節にもそう書いています。
Apple が講じている措置は、[Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/)にあります。Apple は、そのプライバシーの実務がグローバル CBPR システムとグローバル PRP システムに従っていると述べています。その認証機関である BBB National Programs は、Apple Inc. を両方の現在の参加者として示しています。
欧州連合の人がメールを書くと、それは日本にいる運営者（日本には欧州委員会の十分性認定があります）と、米国の Apple の受信箱に届きます。Apple は、欧州経済領域・英国・スイスで集めた個人データの国際移転は標準契約条項によると述べています。

Vercel は、Sophaxis への閲覧の要求の記録（IP アドレスを含みます）を持っています。
運営者はこれを見ることができ、不具合を見つけて直すためだけに使います。
Vercel の説明書によれば、Sophaxis を配信している Hobby プランでは、ランタイムのログは 1 時間保たれます。
閲覧の要求の記録が持つのは、IP アドレス、ブラウザーのユーザーエージェント、求めた頁のアドレス、時刻などの要求の詳細で、名前はありません。
Sophaxis は、IP アドレスを人に結びつけるものを持ちません。アカウントも cookie も解析もありません。ある IP アドレスを誰が使ったかを知るには、その人のネットワークの事業者に照会する必要があります。
個人情報保護法では、それだけで、または他の情報と容易に照合して特定の個人を識別できる情報が個人情報です。委員会のガイドライン（通則編）は、他の事業者への照会を要する場合などを、一般に容易に照合できない状態と読んでいます。
そのため閲覧の要求の記録は、Sophaxis にとって個人情報ではありません。個人データについて定める個人情報保護法第 28 条は、これには掛かりません。
Vercel は、それぞれの要求を、読者のブラウザーから直に受け取ります。Sophaxis が記録から Vercel に渡すものはありません。
本人が自分の IP アドレスを示して自分の要求について尋ねたときは、運営者は、答える間、当てはまる記録をその人の個人情報として扱い、どれも写しません。
Vercel は、その[プライバシーの方針](https://vercel.com/legal/privacy-notice)のとおりに記録を扱い、講じている措置を[データ処理補遺](https://vercel.com/legal/dpa)の別表 2 に公表しています。
毎週、自動の手順が Vercel と Apple のプライバシーの方針の最終更新日を読みます。日付が変われば issue が開き、運営者が方針を読み直して、そのサービスを使い続けてよいかを決めます。

## 安全のための措置

記録は、DOI の登録情報など、すでに公開されている情報だけで作ります。
投稿の自動の検査は、読むものを ORCID の氏名・ウェブサイト・業績に限り、ほかを書き写しません。
検査に与える権限は、必要な最小限にしています。
記録を変えられるのは、運営者だけです。
ただし、削除依頼が個人情報の露出を報告したときは、[削除の規程](./takedown.ja.md)の自動の手順が記録の頁（題・著者・要旨・PDF の写し）を下げます。
法令が報告を求める漏えいが起きたときは、個人情報保護委員会に報告し、本人に知らせます。
報告が要るのは、要配慮個人情報を含むとき、不正に使われると財産の損害が生じうるとき、運営者のアカウントへの攻撃のような不正の目的による行為で漏れたとき、1,000 人を超えるときです。
運営者は、知ったあと速やかに報告し、30 日以内に、不正の目的による行為のおそれがあるときは 60 日以内に、確かな報告をします。

講じている措置を、個人情報保護委員会の区分で示します。

- 組織的な措置：個人データを扱うのは運営者一人で、運営者が責任を負います。記録の変更は、どれも公開のコミットかプルリクエストとして残ります。
- 人的な措置：運営者のほかに、Sophaxis の個人データを扱う人はいません。モデレーターを招く前に、運営者は、モデレーターが扱える個人データと、運営者がどう監督するかをここに書きます。
- 物理的な措置：Sophaxis は、自前のサーバーも紙の記録も持ちません。記録は GitHub のリポジトリに、サイトは Vercel にあります。
- 技術的な措置：自動の手順が持つ鍵は、GitHub が実行ごとに渡す最小限の権限のトークンだけです。Vercel に残る以前の版のサイトは、公開していません。リポジトリを変えられる唯一のアカウントである運営者の GitHub アカウントは、二段階認証を使っています。サイトを配る Vercel には、運営者はこの GitHub アカウントでログインしています。
- 外的環境の把握：「外国にある事業者の利用」に示したとおりです。運営者の受信箱のメールは、iTunes 株式会社に代わって米国の Apple Inc. が取り扱うことがあります。運営者は、要る間だけそこに置き、そこに示した米国の制度を踏まえています。

## 自動の処理

自動の検査は、公開されている記録を照らし合わせ、その結果を issue に書くだけです。人についての判断はしません。
人に法的な効果、またはそれに近い重大な影響を与える判断を、自動の処理だけで下すことはありません。
審査を助ける言語モデルは、判断をしません。投稿についての判断は、モデレーションの規程のとおり、すべて人が下します。

## 欧州連合と英国の人へ

2026-11-22 から、Sophaxis は、欧州連合・欧州経済領域・英国の人にサービスを提供しません。
