# 個人情報の取り扱いについて

最終更新：2026-11-08。

Sophaxis の個人情報の取り扱いを、日本の個人情報保護法の項目に沿って書いたものです。英語の [Privacy Policy](./privacy.html) の訳で、項目を日本の個人情報保護法に沿って並べ替えてあります。英語と違うところは、英語が優先します。

## 取り扱う者

Sophaxis の運営者、根本卓哉です。住所は公開していません。求めがあれば、遅滞なく知らせます。
運営者が個人情報保護法の「個人情報取扱事業者」に当たるものとして、同法の定めをすべて守ります。

## 取り扱う個人情報

- 投稿の issue に載る GitHub のユーザー名と、投稿の様式に書かれた内容
- 載せた論文の著者の氏名と ORCID iD（DOI の登録情報から取ります）
- 本人確認のために読む、ORCID の公開記録のうち、氏名・ウェブサイト・業績
- 撤回や出版版の報告の様式に書かれた内容
- 2026-11-21 から、共著者が同意を確かめるコメントに書く GitHub のユーザー名と ORCID iD

本人確認では、ORCID に、公開記録のうち「個人の詳細」（氏名）・「ウェブサイト」・「業績」の部分だけを問い合わせます。
「人物」の部分をまとめて問い合わせないので、公開のメールアドレスや国を受け取ることはありません。
検査が使うのは氏名・ウェブサイト・業績だけで、ほかは保存せず、どこにも書き写しません。
サイトは、閲覧者の個人情報を集めません。Cookie も、アクセス解析も使いません。
頁には、閲覧者の情報を外へ送るコードもタグもありません。電気通信事業法の外部送信の規律（第 27 条の 12）に当たるものはありません。
検索の頁は、Sophaxis 自身が配るスクリプトを一つだけ動かします。Sophaxis から記録の一覧を読み、閲覧者のブラウザの中で検索し、どこにも何も送りません。ほかの頁はスクリプトを動かしません。
記録の頁には、X・Bluesky・Facebook・LinkedIn・メールへの共有のリンクがあります。どれも各サービスの頁への普通のリンクで、閲覧者がたどるまで何も送られず、たどった先では各サービスの方針が掛かります。
Sophaxis は、Vercel のアクセス解析を有効にしていません。

投稿・撤回・出版版の報告には、ORCID iD と、その ORCID の記録がリンクする GitHub のアカウントが要ります。
これが無いと検査は著者を確かめられず、issue では手続きを進められません。
その場合も、各規程のとおりメールで求めることができます。
ほかには何も求めません。

## 利用目的

- 投稿者が、その論文の著者本人であることを確かめるため
- 2026-11-21 から、同意を確かめる共著者が、その論文の著者本人であることを確かめるため
- 撤回や出版版の報告をする人が、その論文の著者本人であることを確かめるため
- 論文の記録の頁、著者ごとの頁、一覧と検索を作り、公開するため
- 記録を `feed.xml`・`papers.json`・OAI-PMH（`/oai`）で再利用できる形にするため
- 毎週、DOI とライセンスを確かめるため。著者が同意した作品については、頁と PDF の写しを Internet Archive に保存するため（頁が変わったときにも保存します）
- 新しく載った頁、変わった頁、削除した頁の場所を、検索エンジンに知らせるため
- 取り下げ・訂正・削除の求めと、個人情報についての求めに応えるため
- サイトを配信し、Vercel の閲覧の要求の記録から不具合を見つけて直すため
- 問い合わせ・苦情・紛争・安全についての報告に応えるため

ほかの目的には使いません。

## 公開と第三者への提供

著者の氏名と ORCID iD は、記録の頁で公開します。
記録は、`feed.xml`・`papers.json`・OAI-PMH でも公開します。OpenAIRE などの収集者は、そこから題・著者・要旨・ライセンスを写します。
著者が同意した作品の頁と PDF の写しは、Internet Archive（米国）に保存します。
Zenodo に置かれた作品は、Zenodo にある Sophaxis のコミュニティ（https://zenodo.org/communities/sophaxis）にも集めることがあります。
コミュニティに記録を出すのは著者です。記録を持つのは Zenodo で、運営はスイスの CERN です。
Sophaxis はコミュニティから何も写しません。運営者がそこの記録を書き換えることもありません。
2026-11-22 から、Sophaxis を提供しない所（投稿の規程の表にあります）に住む著者の作品の記録を足す依頼は断ります。その作品は Sophaxis に載らないためです。依頼そのものは、CERN の規約のもとで Zenodo に残ります。
投稿の様式で、すべての著者が掲載と、下の「外国にある事業者の利用」に挙げる提供に同意していることを確かめます。Internet Archive への保存は別の同意で、空けておくこともできます。
法令に基づく場合を除き、これ以外に個人情報を第三者へ渡すことはありません。
ほかの者がすでに写したものは、Sophaxis の手の外にあります。

## 外国にある事業者の利用

Sophaxis は、外国にある次の事業者のサービスを使います。
記録に含まれる個人データが GitHub・Vercel・ORCID・Internet Archive に渡ることを、個人情報保護法第 28 条の「外国にある第三者への提供」として扱います。
投稿の様式で、この頁の情報を示したうえで、著者それぞれの同意を求めます。この確認は 2026-11-21 から必須です。
それまでは、運営者以外の著者の作品は、すべての著者が投稿の issue でこの同意を示してから載せます。
Internet Archive への保存の同意は、別の欄で尋ねます。空けておくこともでき、そのときは記録をそこに保存せず、`robots.txt` で Internet Archive に集めないよう求めます。
どの著者も、どちらの同意も、削除の issue かメールでいつでも撤回できます。撤回の前に行ったことは、適法なままです。
Internet Archive への同意を撤回すると、著者からの求めであることを運営者が確かめたうえで、審査なしに保存をやめます。運営者は、それまでの写しを除くよう Internet Archive に頼みます。
GitHub・Vercel・ORCID への提供の同意を撤回すると、記録を削除します。これらが無いと作品を載せられないためです。

- GitHub（米国）：投稿の受け付けと、記録の保管
- Vercel（米国）：サイトの配信。閲覧の要求を、IP アドレスを含めて処理します
- DataCite（ドイツ）・Crossref（米国）：DOI の登録情報を読むため
- ORCID（米国）：ORCID の公開記録を読むため
- Internet Archive（米国）：公開した頁と PDF の写しを保存するため
- OpenAlex（米国）：載せた作品をどう収めているかを、DOI だけで問い合わせるため。人については問い合わせません

それぞれの事業者の個人情報の扱いは、各社の規約によります。
米国には、個人情報についての連邦の一般法がありません。州ごとの法律があります。国全体で個人情報を受け持つ一つの機関はなく、本人が持つ権利は、州と分野によって違います。
ドイツは欧州連合の国で、一般データ保護規則（GDPR）が適用されます。
各国の個人情報の保護の制度については、個人情報保護委員会が情報を公表しています。

各事業者が個人情報を守るために講じている措置は、それぞれの方針にあります。

- GitHub：[GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。EU-米国データプライバシーフレームワークに従うと述べています。
- Vercel：[Vercel Privacy Notice](https://vercel.com/legal/privacy-notice)。EU-米国データプライバシーフレームワークに従うと述べています。
- ORCID：[ORCID Privacy Policy](https://info.orcid.org/privacy-policy/)。毎年、EU-米国データプライバシーフレームワークの基準で評価を受けていると述べています。

GitHub・Vercel・ORCID について、欧州連合からの移転は、各社がその枠組みの認証を受けている限りで、EU-米国データプライバシーフレームワークについての欧州委員会の十分性認定に基づきます。

- Crossref：[Crossref privacy](https://www.crossref.org/operations-and-sustainability/privacy/)
- Internet Archive：[Terms of Use](https://archive.org/about/terms)。受け取るのは公開の頁と PDF の写しだけで、記録がすでに公開している以上の個人データは含みません。Internet Archive が個人情報を守るために講じている措置については、情報を示すことができません。その規約はスクリプトを動かさないと読めず、ほかにその措置を述べたものも見つからなかったためです。

メールでの求めは、Apple のメールの受信箱（iCloud メール、米国）に届きます。
応えることと、応えたことを示すのに要る間だけ、そこに置きます。
Apple が講じている措置は、[Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/)にあります。
欧州連合の人がメールを書くと、それは日本にいる運営者（日本には欧州委員会の十分性認定があります）と、米国の Apple の受信箱に届きます。Apple は、欧州経済領域・英国・スイスで集めた個人データの国際移転は標準契約条項によると述べています。

Vercel は、Sophaxis への閲覧の要求の記録（IP アドレスを含みます）を持っています。
運営者はこれを見ることができ、不具合を見つけて直すためだけに使います。

受信箱の Apple と、閲覧の要求の記録の Vercel は、Sophaxis のために個人データを扱っており、どちらも契約で扱わないと定められてはいません。
個人情報保護委員会の Q&A 7-53 の読み方に沿って、Sophaxis は両者をその取り扱いの委託先として扱い、個人情報保護法第 25 条により監督します。
各社は講じている措置を公表しています。Vercel は[データ処理補遺](https://vercel.com/legal/dpa)の別表 2 に、Apple はプライバシーポリシーに書いています。
毎週、自動の手順が Vercel と Apple のプライバシーの方針の最終更新日を読みます。日付が変われば issue が開き、運営者が方針を読み直して、そのサービスを使い続けてよいかを決めます。

## 安全のための措置

記録は、DOI の登録情報など、すでに公開されている情報だけで作ります。
投稿の自動の検査は、読むものを ORCID の氏名・ウェブサイト・業績に限り、ほかを書き写しません。
検査に与える権限は、必要な最小限にしています。
記録を変えられるのは、運営者だけです。
ただし、削除依頼が個人情報の露出を報告したときは、[削除の方針](./takedown.html)の自動の手順が記録の頁（題・著者・要旨・PDF の写し）を下げます。
法令が報告を求める漏えいが起きたときは、個人情報保護委員会に報告し、本人に知らせます。
報告が要るのは、要配慮個人情報を含むとき、不正に使われると財産の損害が生じうるとき、運営者のアカウントへの攻撃のような不正の目的による行為で漏れたとき、1,000 人を超えるときです。
運営者は、知ったあと速やかに報告し、30 日以内に、不正の目的による行為のおそれがあるときは 60 日以内に、確かな報告をします。

講じている措置を、個人情報保護委員会の区分で示します。

- 組織的な措置：個人データを扱うのは運営者一人で、運営者が責任を負います。記録の変更は、どれも公開のコミットかプルリクエストとして残ります。
- 人的な措置：運営者のほかに、Sophaxis の個人データを扱う人はいません。モデレーターを招く前に、運営者は、モデレーターが扱える個人データと、運営者がどう監督するかをここに書きます。
- 物理的な措置：Sophaxis は、自前のサーバーも紙の記録も持ちません。記録は GitHub のリポジトリに、サイトは Vercel にあります。
- 技術的な措置：自動の手順が持つ鍵は、GitHub が実行ごとに渡す最小限の権限のトークンだけです。Vercel に残る以前の版のサイトは、公開していません。リポジトリを変えられる唯一のアカウントである運営者の GitHub アカウントは、二段階認証を使っています。
- 外的環境の把握：「外国にある事業者の利用」に示したとおりです。

## 自動の処理

自動の検査は、公開されている記録を照らし合わせ、その結果を issue に書くだけです。人についての判断はしません。
人に法的な効果、またはそれに近い重大な影響を与える判断を、自動の処理だけで下すことはありません。
運営者の判断の前に動く手順が一つだけあります。削除依頼が個人情報の露出を報告したとき、記録の頁（題・著者・要旨・PDF の写し）を下げる手順です。
本人を守るためのもので、依頼が認められなければ元に戻します。
自動の手順は、[What runs by itself](../automation.html) の頁にすべて挙げています。

## 保存の期間

記録は、引用が壊れないよう、期限を設けずに保ちます。
issue とそこに載る GitHub のユーザー名は、GitHub が issue を保つ間、残ります。記録を削除すると、その記録を名指す issue を空にし、運営者がそのあと削除します。
Vercel の閲覧の要求の記録は、そのサービスが定める期間だけ残ります。運営者はそれを写しません。
削除の求めがあれば、[削除の規程](./takedown.html)に沿って記録を削除します。
著者の求めでも削除します。
削除した記録に残るのは、Sophaxis の番号と削除の日だけです。
公開のリポジトリの履歴と、Internet Archive の保存には、以前の版が残ります。
運営者は、GitHub と Internet Archive にその削除を頼みます。

## 開示・訂正・利用停止・削除の求め

本人は、Sophaxis が持つ自分の個人データについて、開示・訂正・利用の停止・削除を求めることができます。
利用目的を知らせること、正確さや異議を確かめる間の利用の制限、第三者への提供の停止も求めることができます。制限の間、運営者は該当する部分を下げます。
投稿の issue とその同意、公開のリポジトリにある記録の履歴が、第三者提供の記録（個人情報保護法第 29 条）です。本人は、自分に関わる部分の開示を求めることができます。
記録に載っていない個人データ（issue の GitHub のユーザー名、Vercel の記録の IP アドレスなど）についての求めは、メールで受け付けます。
求めは、削除の issue で受け付けます。
issue は公開されるので、個人情報は書かず、Sophaxis の id と求めの種類だけを書く形にします。
公開の場で求めにくいときは、運営者の [ORCID の記録](https://orcid.org/0009-0000-1406-0547)にあるメールアドレスへ送る形でも受け付けます。
個人データについての求めに答える前に、運営者は、ORCID の記録かメールで、求めた人が誰かを確かめます。
求めは、親権者・保護者や本人が選んだ人などの代理人を通してもできます。そのときは、本人であることに加えて、代理の権限を確かめます。
個人データの開示は、メールで、広く使われる電子の形か、本人が求める方法で行います。issue には書きません。
OAI-PMH の入口にも、収集者のためのアドレスがあります。この規格がアドレスを求めるためです。個人情報についての求めは、ORCID の記録のアドレスで受け付けます。
運営者は、7 日以内に応えることを目安にします。
個人データについての求めには、遅くとも 1 か月以内に応えます。
もっと時間が要るときは、その 1 か月のうちに理由を添えて知らせ、求めから 3 か月以内に応えます。
求めのとおりにしないときは、1 か月以内に理由を知らせます。データ保護機関への苦情と、裁判所に訴えることができることも知らせます。
求めがあれば、訂正・削除・制限をどの受け手に知らせたかを伝えます。
求めに費用はかかりません。
個人情報の扱いへの苦情も、同じアドレスで受け付けます。
[個人情報保護委員会](https://www.ppc.go.jp/)に相談することもできます。
スイスの人は、スイスの連邦データ保護・情報コミッショナーに苦情を申し立てることもできます。

## 異議を述べる権利

誰でも、いつでも、自分の事情を理由に、Sophaxis での自分の個人データの利用に異議を述べることができます。
異議は、削除の issue かメールで受け付けます。
異議を受けたら、運営者は、本人の利益・権利・自由に優る、やむを得ない正当な理由を示せるときと、法的な請求に要るときを除いて、その利用をやめます。
その理由は、書面で示します。

## 欧州連合と英国の人へ

2026-11-22 から、Sophaxis は、欧州連合・欧州経済領域・英国の人にサービスを提供しません。
そこに住む著者のいる作品は載せず、投稿の様式で投稿者にこのことを確かめます。
これは住んでいる場所だけで決まり、国籍・人種・民族その他の個人の属性によるものではありません。
サイトは誰でも読めますが、Sophaxis はそこの人に向けて運営していません。
そのため運営者は、一般データ保護規則と英国の一般データ保護規則は、第 3 条第 2 項によっては Sophaxis に及ばないと考えています。
それでも、この節に書く権利は、当てはまる限り守ります。
欧州連合と英国の人については、この取り扱いの根拠は正当な利益です。著者を確かめること、公開の学術記録を保つこと、サイトを安全に配信すること、連絡をくれた人に応えることです。
記録は、学術記録を保つために、表現と情報の自由のために残します（第 17 条第 3 項 a）。
十分性の認定もほかの保護措置もない欧州連合の外への移転は、著者の明示の同意に基づきます（第 49 条第 1 項 a）。Internet Archive への移転がこれに当たります。
その移転の起こりうる危険を、同意の前に示します。Sophaxis は、Internet Archive に掛かる十分性の認定もほかの保護措置も知りません。そのため、そこに保存された個人データは、一般データ保護規則のもとより弱くしか守られないことがあり、本人がそこで権利を行使することも難しいことがあります。
この同意は別の欄で尋ね、削除の issue かメールで、いつでも撤回できます。そのとき Internet Archive への保存は審査なしにやめます。撤回の前に行ったことは、適法なままです。
本人は、自分が示した個人データを、構造化され、広く使われ、機械で読める形で受け取るよう求めることもできます（第 20 条）。`papers.json` と OAI-PMH の入口が、すべての記録をすでにその形で示しています。
本人は、上の「異議を述べる権利」のとおり異議を述べることができます。自国のデータ保護機関に苦情を申し立てることもできます。
欧州連合と英国に代理人（第 27 条）は置いていません。
置かないと決めています。
代理人は、有料のサービスか、欧州連合や英国にいて Sophaxis の責任を引き受ける人になります。
Sophaxis は、無報酬で、無料の範囲で運営しています。
第 3 条第 2 項についての上の考えが誤っていれば、代理人がいないので、Sophaxis は第 27 条を満たしていません。取り扱いは継続的なものなので、時折の取り扱いの例外には当たりません。
運営者は、運営者以外の著者の作品を初めて載せたときに、この判断を見直します。データ保護機関、または欧州連合や英国にいる人から代理人を求められたときも、そのつど見直します。
見直しのたびに、その結果を公開のリポジトリに記録します。
見直しでは、二つの道を比べます。代理人を置くことと、法人を通して Sophaxis を運営することです。
