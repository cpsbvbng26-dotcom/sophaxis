## この規約が及ぶ人

この規約は、Sophaxis を読む人と、Sophaxis に投稿する人のすべてに及びます。
投稿者は、投稿の様式で、その日の版のこの規約に同意します。
Sophaxis を読むことを、何かへの同意とはみなしません。読む人にとって、この規約は Sophaxis の仕組みを示すもので、双方が負うものは法令が定めます。
ほかの規程も、この規約の一部です。
コンテンツのモデレーションの仕方は、モデレーションの規程と削除の規程に定めています。そこに関わる自動の手順は、[自動で動く手順](../automation.ja.md)の頁にすべて挙げています。

## Sophaxis が提供するもの

Sophaxis は、哲学・数学・論理学・数理哲学・科学哲学のプレプリントを載せます。
載せた作品のそれぞれに、記録の頁、検索、フィードを与えます。預け先が許す場合は、PDF の写しも置きます。
これらを無料で行います。

## 著者がすべての責任を負う

著者は、自分の作品と、それを Sophaxis に載せることについて、すべての責任を負います。
次のものを含みます。

- 作品の内容。主張・証明・引用・計算・図のすべてを含みます。
- その版をそのライセンスで共有する権利と、出版者の許諾。
- 作品の中の他人の素材と、著作権その他の権利の侵害。
- 作品の中の第三者の個人データ。
- 生成モデルについての申告と、そこに書かれていない使用。
- [投稿の規程](./submission.ja.md)で投稿者が確認する事柄が、すべて真実であること。

モデレーションによって、これらのどれかが運営者に移ることはありません。
掲載が示すのは、投稿が[モデレーションの規程](./moderation.ja.md)の確認を通ったことだけです。
投稿時に投稿者が確認した事柄が真実でなかったために、第三者が Sophaxis や運営者に請求をした場合、法令の定めるところにより、著者がその責任を負います。
著者は、[削除の規程](./takedown.ja.md)に沿って削除の求めを検討するあいだ、記録の頁（題・著者・要旨・PDF の写し）を公開から外すこと、そのあいだ OAI-PMH がその記録を削除済みとして示すことに同意します。
様式に書かれた文は、[ライセンスの規程](./licences.ja.md)が定めるとおりに共有します。
運営者は、それでも[削除の規程](./takedown.ja.md)に沿って求めに応じます。
様式でこの規約に同意していない共著者は、法令がそうする範囲でだけ、この規約に拘束されます。その人にとって、この節は、法令がすでに作品の著者に負わせていることを述べるものです。

## 読者ができること

読者は、載っている作品のそれぞれを、その作品自身のライセンスに沿って、読み、ダウンロードし、再利用できます。
このサイトの文は、[ライセンスの規程](./licences.ja.md)が定めるとおり、CC BY 4.0 で再利用できます。

## してはいけないこと

- 自分が著者でない作品を投稿すること。
- 著作権その他の権利を侵害する素材を投稿すること。
- 法令上の根拠なく、第三者の個人データを投稿すること。
- スパム、嫌がらせ、サイトや投稿の手続きを妨げようとすること。
- 様式で、事実でないことを確かめること。例として、著者の住んでいる場所や滞在している場所、投稿者の年齢、著者の同意、生成モデルの使用についての申告があります。

運営者は、これらの決まりに反する投稿を、断り、または削除することがあります。
確認が事実でないと分かったときは、運営者は、知った時点で[削除の規程](./takedown.ja.md)に沿って記録を削除します。2026-11-22 からは、同じ GitHub アカウントや ORCID iD からのその後の投稿を断ることもあります。
運営者は、確認を信頼して受け、確かめません。事実でない確認で載った作品があっても、[投稿の規程](./submission.ja.md)が提供しないとする国と地域で、Sophaxis を提供していることにはなりません。
確認は公開の issue に残るので、何をいつ確かめたかを示せます。
投稿者に、違約金や、法令が定める以上の損害の賠償を求めることはありません。

## 変更と終了

この規約とほかの規程は、変わることがあります。
各頁の日付が最後の変更を示し、過去の版は公開のリポジトリに残ります。
頁と、規程の変更の配信と、告知と、お知らせの日付は、日本時間の日付です。
文を取り寄せた日は、取り寄せの記録に残った協定世界時の日付です。
どの変更によっても、料金は生じません。

著者や読者の権利を奪い、または狭める変更と、義務を加える変更は、効力を持つ前に、変わる中身とその開始日を添えて、トップの頁で告知します。
告知は少なくとも 14 日前に行います。ただし、法令や、安全や法的なリスクのような差し迫った問題が、より早い変更を求める場合は、この限りではありません。

規程の変更は、公表または告知した日に、[規程の変更の配信](https://sophaxis.vercel.app/policies/changes.xml)にも載せます。この配信には、ほかのものを載せません。
文をわかりやすくすることや、例を足すことのようなほかの変更は、頁に示した日に効力を持ちます。その日が公開の日より前になることはありません。
変更は、日本の民法第 548 条の 4 が認めるときにだけ行います。著者と読者の一般の利益に合うとき、またはこの規約の目的、変更の必要、変更後の中身に照らして合理的なときです。

変更を受け入れない人は Sophaxis の利用をやめることができ、著者は[撤回の規程](./withdrawal.ja.md)に沿って自分の作品を撤回できます。

## 続けるための備え

Sophaxis は一人で運営しており、失うものなく止められるように組んでいます。

- 判断が遅いことは、休止ではありません。モデレーションには数週間から数か月かかることがあります。休止とは、病気などのために、運営者が Sophaxis の作業をまったくできないときのことです。それが 30 日を超えて続く場合、トップの頁で新しい投稿の受け付けを休止していることを示します。載っている記録は公開したままです。
- 運営者が行動できない場合を除き、閉鎖は少なくとも 30 日前にトップの頁で告知し、先に新しい投稿の受け付けを止めます。
- Sophaxis を閉じる場合、運営者は、すべての記録を収めたリポジトリを公開のまま残し、記録を読めるようにします。著者全員が同意した作品の頁と PDF の写しは、毎週 Internet Archive にも保存しています。
- コードと記録は、版を出すたびに Zenodo に保存しています。いちばん新しい版を指す DOI は [10.5281/zenodo.24033371](https://doi.org/10.5281/zenodo.24033371) です。
- 運営者は、Sophaxis をほかの人、機関、または法人に引き継ぐことがあります。引き継ぎは先にサイトで告知し、新しい運営者が通常の手続きで変えるまで、この規約は効力を保ちます。
- 誰でも、リポジトリを写し、そのライセンスのもとで、ほかの場所で作業を続けられます。文は CC BY 4.0、コードは MIT です。載っている作品は、それぞれ自身のライセンスを保ちます。このリポジトリが引き、または引用を確かめるために置いている他人の文は、CC BY 4.0 で許諾しておらず、それぞれの権利者のものです。
- DOI は、Sophaxis に何があっても、それを発行した預け先に残ります。

### 運営者が作業できないとき

運営者が Sophaxis の作業をまったくできないあいだに起こることを、順に記します。

1. 知らせる先：上のとおり、トップの頁と投稿の頁で新しい投稿の受け付けを休止していることを示し、お知らせでも同じことを伝えます。開いている投稿の issue には、それぞれ判断を待つことを伝えます。運営者が休止を前もって見込めるときは、休止の前にこれらを済ませます。
2. 止まるもの：投稿を受理することも断ることもせず、運営者は記録を足すことも、変えることも、撤回することもしません。休止のあいだに開かれた投稿の issue にも自動の確認は付き、判断を待ちます。運営者なしに記録が変わるのは、4 番の場合だけです。
3. 公開のまま残るもの：すべての記録の頁、PDF の写し、一覧、検索、フィード、JSON の記録、OAI-PMH の入口です。DOI の週ごとの確認はひとりでに続きます。Internet Archive への週ごとの保存も、作品の著者全員が同意したものについて続きます。
4. 運営者がいなくても働くもの：個人情報の露出を報告する削除の申し立ては、削除の規程のとおり、記録の題・著者・要旨・PDF の写しをすぐに下げます。申し立ての判断は、運営者を待ちます。
5. 引き継げる人：記録はリポジトリで公開しており、版を出すたびに Zenodo に保存しています。そのため、後を継ぐ人や、記録を読める状態に保つ預かり手は、運営者だけが持つものを要しません。Sophaxis そのものの引き継ぎは、下のとおり先に告知します。誰でも、下のライセンスのもとで記録を写し、ほかの場所で続けることもできます。
6. 運営者が戻ったら、休止の知らせを外し、待っていた issue を届いた順に判断し、投稿の受け付けを再び始めたことをお知らせで伝えます。

## 紛争

Sophaxis や載っている作品についての紛争は、できるかぎり合意で解決します。

1. まず運営者に連絡します。運営者の [ORCID の記録](https://orcid.org/0009-0000-1406-0547)にあるメールアドレスへ送るか、公開してよい事柄なら issue に書きます。何についての紛争か、何があれば解決するかを書きます。
2. その後、双方が誠実に話し合い、合意を目指します。2026-11-25 までは、運営者は 7 日以内に答え、紛争を返事のないまま放置しません。2026-11-26 からは、運営者は 7 日以内に答えることを目指し、紛争を返事のないまま放置しません。上の「続けるための備え」の休止のあいだは、答えは休止が終わるまで待ちます。
3. 話し合いで 60 日以内に解決しない場合、どちらの側も、裁判の前に、日本の簡易裁判所の民事調停のような調停を申し出ることができます。

2026-11-25 から、これらの方法で解決しない紛争は、様式でこの規約に同意した人との間では、宇都宮地方裁判所または宇都宮簡易裁判所を、第一審の合意管轄裁判所とします。この合意は専属的なものではありません。
それまでは、同じ条件で、運営者の住所地を管轄する地方裁判所または簡易裁判所を、第一審の合意管轄裁判所とします。
2026-11-26 から、この裁判所の合意の対象は、この規約に基づく訴えと、この規約のもとでのその人自身の作品の投稿・掲載・訂正・撤回・削除に基づく訴えに限ります。それ以外の紛争は、法令の定める裁判所が管轄します。
それ以外の人との間では、法令の定める裁判所が管轄します。
運営者の住所は、[運営者と連絡先](../contact.ja.md)の頁にあるとおり、求めがあれば知らせます。
これは、消費者や日本国外の人が、法令によって別の裁判所で訴えを起こし、または応じる権利を奪うものではありません。
この節のどの定めも、誰かが裁判所に緊急の救済を求めることや、[削除の規程](./takedown.ja.md)を使うことを妨げません。

## 日本国外の方へ

Sophaxis は日本から運営しており、どこからでも読めます。

- 同じ手順が適用されます。話し合いと調停は、書面やオンラインで、英語か日本語で行えます。紛争を解決するために、誰も日本へ来る必要はありません。
- この規約は日本法に準拠します。その人自身の国の法令が、合意で排除できない保護、たとえば消費者の保護を与えている場合、その保護は引き続き適用されます。
- 日本国外の人が、自国の法令に基づいて自国の裁判所に訴えることができる場合、その権利は残ります。上の裁判所についての合意が、それを奪うことはありません。
- この規約は英語で書かれており、この日本語の訳を公開しています。訳が英語の文と食い違う場合は、英語の文が適用されます。

## GitHub と Vercel

Sophaxis は、米国に拠点を置く二つのサービスの上で動いており、それぞれの規約もこの規約と並んで適用されます。

- Sophaxis に投稿することは、GitHub を使うことを意味します。issue を開くこと、コメントすること、ファイルを添付することは、利用者と GitHub とのあいだで、GitHub の利用規約とプライバシーステートメントに従います。
- Sophaxis を読むことは、Vercel から頁を受け取ることを意味します。Vercel は、IP アドレスを含むそれぞれの要求を、自らの規約と個人情報の方針に沿って、日本や読者の国以外の国で処理することがあります。
- この規約が拘束するのは、運営者と Sophaxis を使う人です。GitHub や Vercel を拘束せず、GitHub や Vercel に対する請求権も、GitHub や Vercel が行ったことについての運営者に対する請求権も、誰にも与えません。
