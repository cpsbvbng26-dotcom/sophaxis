# 削除の規程（日本語訳）

最終更新：2026-11-11。

これは英語の [Takedown Policy](./takedown.md) の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。このことは、[利用規約](./terms.ja.md)の「日本国外の方へ」の節に定めています。

この頁が引く法令・ライセンス・規約の文は、引いている節の終わりに置いています。
日本の法令は、e-Gov 法令 API が示す条文を全文で引いています。ほかの文は、公式の出どころから 2026-11-11 に取り寄せた文を、語のまま引いています。訳は付けていません。
原文を取り寄せられなかった条は、引いていないことと、その理由を記しています。

## 記録を削除するとき

記録は消しません。
記録を削除しても、Sophaxis の番号はすべて残ります。
記録を削除するのは、三つの場合です。
一つ目は、著作権の侵害や個人データの露出のように、法令が削除を求める場合です。
二つ目は、著者が掲載に同意していなかったことを示し、その作品を[撤回の規程](./withdrawal.ja.md)で撤回できない場合です。
三つ目は、[撤回の規程](./withdrawal.ja.md)が定めるとおり、作品の著者が撤回の issue で削除を求めた場合です。
削除した記録に残るのは、下の「削除した記録に残るもの」の節に挙げるものだけです。

## 求め方

法的な理由で削除を求めるときは、削除の issue を開きます。
issue に個人データを書かないでください。
問題の素材そのものを繰り返さずに、問題がどこにあるかを書きます。
著者として、権利者として、データが載っている本人として、またはその代理として、のどの立場で関わっているかを書きます。

求めは、どの国からでも、英語か日本語で受け付けます。
求めは、求める人の国の法令に基づくものでも構いません。たとえば米国の法令に基づく著作権の通知や、欧州連合のデータ保護法に基づく求めです。
運営者は、この規程と日本法に沿って検討し、どちらかが求める場合は素材を公開から外します。

サイトは Vercel が配信し、リポジトリとその issue は GitHub が保管しています。どちらも米国にあります。
求めは、たとえば GitHub 自身の手続きでの著作権の通知として GitHub に、または Vercel に送ることもできます。
GitHub と Vercel は、それぞれの規約で判断します。運営者は、それがどう判断しても、Sophaxis についてはこの規程で判断します。
運営者が素材を削除する場合は、下に定めるとおり、リポジトリの履歴からの削除も GitHub に求めます。

公開の場で行えない求めは、運営者の [ORCID の記録](https://orcid.org/0009-0000-1406-0547)にあるメールアドレスへメールで送ります。
それが求めのための宛先です。OAI-PMH の口にある宛先は、収集者のためのものです。
個人データやそのほかの重大な害については、運営者は、求めを検討するあいだ、記録の頁（題・著者・要旨・PDF の写し）を公開から外します。著者は[利用規約](./terms.ja.md)でこれに同意しています。

## 求めを受けた後

運営者は、それぞれの求めに 7 日以内に答えることを目指します。
個人データやそのほかの重大な害については、判断の前に、記録の頁（題・著者・要旨・PDF の写し）をただちに公開から外し、戻すまで OAI-PMH はその記録を削除済みとして示します。
削除の issue には、運営者が答える目安の日を添えた受領の知らせが自動で付きます。
削除の issue が個人データの露出を報告している場合、運営者が読む前に、記録の頁（題・著者・要旨・PDF の写し）が自動で公開から外れます。
自動の処理は何も決めません。どの求めも運営者が判断します。
著者には、その投稿の issue で知らせ、著者は応答できます。
求めた人自身の個人データについての求めは、作品ではなくその人に関わるものなので、著者には知らせません。
重大な害のためにただちに外す場合を除き、運営者は、求めに沿って素材を外す前に、著者に同意するかどうかを尋ねます。7 日以内に反対がなければ、外すことがあります。
この通知と応答の手続きは、インターネット上のサービスの提供者の責任に関する日本の法令の考え方に沿ったものです。素材に関わる人は、判断の前に求めを知り、答えることができます。ただし、重大な害のために素材をただちに公開から外す必要がある場合は除きます。

求めが認められた場合、記録は次の節のとおり削除します。
求めが認められなかった場合、運営者はその理由を issue で示します。
検討のあいだ公開から外していた素材は、元に戻します。
戻す前に、判断を issue に書くか、メールで求めた人にはメールで送ります。
著者はいつでも求めに答えることができ、その答えから求めに根拠がないと分かった場合は、素材を元に戻します。

## 削除した記録に残るもの

この節は、理由にかかわらず、削除したすべての記録に適用されます。
削除は、運営者の判断の後、公開のリポジトリにある `tools/removal.js` が行います。下の各段階は、公開する前に自動で確かめます。

サイトでは：

- 記録を削除すると、その頁は、その Sophaxis の番号の記録を削除したことだけを述べる告知に置き換わります。
- 告知には、理由もほかの詳細も書きません。
- 引用が何もない所ではなく告知へ届くように、アドレスは働いたままにします。
- 題・著者・要旨・PDF の写しは、サイトから外します。
- 頁は検索エンジンに索引しないよう求め、記録はすべての一覧、検索、フィード、`papers.json`、サイトマップから外れます。統計では、削除した記録としてだけ数えます。
- Vercel が保持しているサイトの過去の版は、公開しません。
- `robots.txt` で、Internet Archive のクローラーに、その頁と PDF の写しを再び集めないよう求めます。

記録と OAI-PMH の口では：

- 記録には、Sophaxis の番号、「removed」の語、削除の日だけが残ります。日を残すのは、OAI-PMH の口がそれを必要とするためです。
- OAI-PMH の口は、その日を添え、メタデータなしで、記録を削除済みとして示します。収集者が次に訪れたときに取り除けるようにするためです。

issue では：

- その記録についての自動のコメントはすべて消し、その記録を挙げる issue は中身を空にして閉じ、ロックします。その後、運営者がそれらを削除します。
- issue を削除すると、その編集履歴も消えます。
- 削除の求めそのものは、それへの判断とともに残ります。削除を求めた撤回の issue は、ほかと同じように中身を空にします。

サイトの外では：

- 運営者は、リポジトリの履歴からの素材の削除も GitHub に求めます。
- GitHub が削除するまで、記録の過去の版は公開のリポジトリの履歴に残ります。
- GitHub 自身の手続きでは、先に持ち主が履歴を書き換え、そのあと GitHub のサポートに頼みます。サポートが手伝うのは、ほかに危険を除く手のない機微なデータだけです。手伝わないときは、過去の版は履歴に残ります。
- 運営者は、Internet Archive にも、その記録の過去の写しを除外するよう求めます。
- ほかの者がすでに取った写しは、Sophaxis の手の外にあります。運営者は、知っているものには知らせます。
- これらの手順は、後始末の issue にまとめます。Internet Archive への依頼の文面も添えます。毎日、自動の手順が、空にした issue が削除されたかと、Wayback Machine に写しが残っているかを確かめ、済んだものに印を付け、残りを週に一度、運営者に知らせます。

削除した記録の Sophaxis の番号は、ほかの作品に与えることはありません。

## 欧州連合のデジタルサービス法について

2026-11-22 から、Sophaxis は、著者のだれかが欧州連合に住んでいるか、投稿から掲載までのあいだにそこに滞在している作品を載せず、そこの人に向けて運営していません。そのため運営者は、Sophaxis は欧州連合と実質的なつながりを持たず、この法の意味でそこにサービスを提供していないと考えています。
Sophaxis はここでも最も厳しい場合を想定し、その規模のサービスに当てはまりうる範囲で、欧州連合のデジタルサービス法に従います。

- 当局・欧州委員会・Sophaxis を使う人のための連絡窓口（第 11 条・第 12 条）は、運営者の [ORCID の記録](https://orcid.org/0009-0000-1406-0547)にあるメールアドレスで、英語か日本語で受け付けます。Sophaxis は欧州連合に法定代理人を置いておらず（第 13 条）、運営者は、[個人情報の取り扱いについて](./privacy.ja.md)が示す理由により、置かないと決めています。当局はそのアドレスで運営者に直接連絡します。上の考えが誤っていれば、欧州連合に法定代理人がいないので、Sophaxis は第 13 条を満たしていません。
- 違法なコンテンツの通知（第 16 条）は、削除の issue かメールで行います。メールでの通知には、送る人の名とメールアドレスを書きます。削除の issue は公開されるので、これらを書きません。代わりに、issue を開いた GitHub のアカウントがその役を果たします。メールでの通知には、書いたことが正確で完全だと誠実に信じていることも書きます。削除の issue には受領の知らせが自動で付きます。メールでの通知には、運営者が遅滞なくメールで受領を知らせます。判断は issue かメールで知らせます。
- 判断の理由（第 17 条）は、運営者が、すべての判断について削除の issue かメールで示します。著者には、求めが届いた時点でその issue を知らせています。理由には、自動の処理が働いたかどうかを書きます。働くのは露出した個人データをただちに公開から外す処理だけで、それは求めが挙げた問題の種類に応じて働きます。素材を違法と判断したときは、理由に、拠った法令と、素材がそれに反するわけを書きます。措置の及ぶ範囲と期間も書きます。削除は、サイトがどこで読まれても及び、恒久のものです。メールでの求めを認めたときは、個人データを含めずに書いた理由を、空にする前の著者の投稿の issue に書きます。GitHub がそれを、その issue を見ている著者に送ります。理由が無いと、削除の手順は動きません。著者は、運営者にメールで理由を求めることもできます。
- 判断への異議（第 20 条）は、通知を送った人と著者が、六か月以内に、削除の issue での返答かメールで申し立てることができます。費用はかかりません。運営者が見直して答え、見直しを自動の処理に任せることはありません。
- 裁判所に訴えることも、第 21 条で認証された裁判外の紛争解決機関を使うこともできます。
- 重大な犯罪の疑い（第 18 条）：人の生命や安全を脅かす犯罪の疑いを生じさせる情報を知ったときは、運営者は、関係する加盟国の法執行機関か司法機関に、持っている関係の情報をすべて添えて速やかに知らせます。その加盟国を十分な確かさで特定できないときは、欧州刑事警察機構（Europol）に知らせます。
- 載せてよいものを制限する決まりは、[利用規約](./terms.ja.md)とこれらの規程に、平易な英語で書いてあります（第 14 条）。
- 月ごとの平均の利用者数（第 24 条第 3 項）：Sophaxis は、アクセス解析も読者を見分ける識別子も持たず、この数を出すために持ち始めることもしません。デジタルサービス調整官か欧州委員会から求められたときは、直近六か月の月ごとに、Sophaxis に投稿・通知・連絡をした欧州連合の人の数を issue とメールから数えて示し、読者は数えていないことを添えます。
- [統計](https://sophaxis.vercel.app/stats.html)は削除した記録を数え、公開の削除の求めのすべてへリンクしています。

## 米国法による著作権の通知

Sophaxis は、手数料の掛かる米国著作権局への代理人の届け出をしていません。そのため、米国著作権法第 512 条の責任の制限には拠りません。
その法による侵害の通知も、ほかの求めと同じく、この規程に沿って扱います。

## 素材を送った人の開示の求め

素材を投稿した人の開示を求められた場合は、日本の法令が定めるとおりに扱います。
運営者は、まず関係する人に意見を聴きます。
運営者は、法令が求めないものは開示しません。

## 預け先にある作品

Sophaxis は、Zenodo、Figshare その他の預け先から作品を削除できません。
預けたものそのものについての求めは、その預け先へ送ります。
