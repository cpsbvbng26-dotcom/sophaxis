# 撤回の規程（日本語訳）

最終更新：2026-11-07。

これは英語の [Withdrawal Policy](./withdrawal.html) の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。このことは、[利用規約](./terms.ja.html)の「日本国外の方へ」の節に定めています。

## 撤回できる人

載っている作品の著者なら、誰でも一人で撤回できます。
作品は、すべての著者が同意しているあいだだけ載せるので、一人の著者がその同意を取り下げると掲載は終わります。

求めは、投稿のときと同じく、著者自身の GitHub のアカウントから出します。
著者の ORCID の記録がそのアカウントにリンクしており、その ORCID iD が作品の著者のものでなければなりません。
自動の確認が両方を確かめ、結果を issue に書きます。

## 求め方

撤回の issue を開き、Sophaxis の番号、ORCID iD、短い理由を書きます。
理由は記録の頁に出るので、個人データを含めてはいけません。
issue は公開されます。

公開の場で行えない求めは、運営者の [ORCID の記録](https://orcid.org/0009-0000-1406-0547)にあるメールアドレスへメールで送ります。
その場合、運営者は、issue で確認が行うのと同じく、ORCID の記録で著者であることを確かめます。

## 求めを受けた後

運営者は、確かめられた求めから 7 日以内に対応することを目指します。
引用が切れないように、記録の頁は、アドレス・題・著者・要旨・版を保ちます。
頁の先頭の告知に、撤回の日と理由を書きます。
記録は、撤回済みの印を付けて、一覧・検索・フィード・`papers.json` に残ります。
PDF の写しはサイトから外し、記録は預け先へのリンクだけになります。
撤回した記録には、新しい版を加えません。
過去の写しは、公開のリポジトリの履歴と Internet Archive に残り、OAI-PMH の口の収集者は、取ったものを保ちます。

## 著者の求めによる削除

著者は、同じ issue で、撤回の代わりに記録の削除を求めることができます。
様式で、二つのうちどちらを望むかを尋ねます。
同じ確認で、求めているアカウントが作品の著者のものであることを確かめます。
すでに撤回した記録も、削除できます。
運営者は、確かめられた issue に `upheld` のラベルを付けて記録を削除し、7 日以内に行うことを目指します。
その後に残るのは、[削除の規程](./takedown.ja.html)の「削除した記録に残るもの」の節が定めるとおり、Sophaxis の番号だけです。
理由は示さず、撤回の issue そのものも中身を空にして閉じ、ロックします。

## 著者の名前

クリエイティブ・コモンズのライセンスが定めるとおり、著者は、記録から自分の名前を外すよう求めることができます。
運営者は、合理的に可能な範囲でそれに応じ、記録は残します。

## 預け先にある作品

Sophaxis での撤回は、預けたものに手を触れません。
Sophaxis は、Zenodo、Figshare その他の預け先にある作品を撤回したり削除したりできません。預けたものについての求めは、その預け先へ送ります。
預け先が預けたものを撤回したり削除したりした場合、毎週の確認で DOI が解決しなくなったことが分かり、運営者はその旨の注記を付けて記録を撤回します。

## 出版に伴う撤回

出版者の中には、作品が出版されたときにプレプリントを外すよう著者に求めるものがあります。
その場合、著者なら誰でも一人で、上のとおり掲載を撤回できます。
出版された版が記録されていれば、記録の頁はそこへのリンクを保ちます。プレプリントの引用をたどった読者が、出版された版に行き着けるようにするためです。
著者は、撤回を求める前に、出版された版を報告できます。撤回した記録には、新しい報告を受け付けません。

## 撤回と削除

撤回は著者の判断で、記録は残ります。
削除は、著作権の侵害や個人データの露出のような法的な理由によるもので、題・著者・要旨をサイトから外します。
削除は[削除の規程](./takedown.ja.html)に従います。
