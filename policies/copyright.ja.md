# 著作権の規程（日本語訳）

最終更新：2026-11-14。

これは英語の [Copyright Policy](./copyright.md) の訳です。訳と英語の文が食い違うときは、英語の文が適用されます。このことは、[利用規約](./terms.ja.md)の「日本国外の方へ」の節に定めています。

著作権の規程は、著作権が著者に残ることと、Sophaxis が何をなぜ写すかを定めます。

この頁が引く法令・ライセンス・規約の文は、引いている節の終わりに置いています。
日本の法令は、e-Gov 法令 API が示す条文を全文で引いています。ほかの文は、公式の出どころから 2026-11-12 に取り寄せた文を、語のまま引いています。訳は付けていません。
原文を取り寄せられなかった条は、引いていないことと、その理由を記しています。

## 著作権は著者に残る

Sophaxis は、著作権の譲渡も、独占的な許諾も求めません。
作品は、著者が預け先で付けたライセンスのままです。

## Sophaxis が写すものと、その根拠

題・著者名・ライセンス・日付は、DataCite と Crossref が再利用のために公開している DOI のメタデータから取ります。Jxiv については、JaLC の公開のメタデータから取ります。
要旨は作品の一部です。
要旨は、作品自身のライセンスのもとで、著者と作品へのリンクを添えて示します。

Sophaxis は、検索エンジンが本文を索引できるように、載っているそれぞれの版の PDF の写しを、手を加えずに置きます。
スクリプトで写すのは、スクリプトでファイルを取ることを自らの頁で認めている預け先からだけです。Zenodo と arXiv です。
Zenodo の開発者向けの文書は、REST API でできることに「Files — download/upload of files.」を挙げます。
arXiv の一括取得の頁は「We ask that users intent on harvesting use the dedicated site export.arxiv.org for these purposes, which contains an up-to-date copy of the corpus and is specifically set aside for programmatic access.」と書きます。Sophaxis は、その所から取ります。
arXiv の API の利用規約は、e-print を保って配ることを禁じます。例外は「unless you have the permission of the copyright holder or are permitted to do so by the license with which the e-print was submitted」の場合です。載せる作品は、どれも受け付ける三つのライセンスのどれかを持ち、そのライセンスがこれを認めています。
この変更を公開した 2026-11-13 までは、Figshare と Research Square からもスクリプトで写していました。公開してからは写しません。どちらの規約も、これを禁じているためです。
Figshare の規約は、利用者がしてはならないことに「use any manual or automated means, including robots, scripts, or spiders to access, monitor, crawl, scrape, spider or mine」を挙げます。例外は「expressly authorized for you by Figshare in advance in writing」の手段だけです。
Research Square の規約は「You also agree that you will not use any robot, spider, other automated device, or manual process to monitor or copy any content from the Web Sites」と書きます。
Figshare からすでに写したものは、作品のライセンスのもとで残します。
これらの頁は 2026-11-12 に読みました。Zenodo と arXiv の頁は直に読み、Figshare と Research Square の頁は Internet Archive の写しから読みました。
預け先がチェックサムを公開している場合、写しはそれと一致しなければなりません。
預けたものに PDF が複数ある場合、Sophaxis はどれが論文かを推測せず、写しを作りません。
Figshare と Research Square を含むほかの預け先については、著者が、預けた PDF を投稿の issue に添付できます。
その場合、Sophaxis はそのファイルを手を加えずに置き、記録には著者が提供したと書きます。
そのようなファイルが無ければ、記録は預け先へのリンクだけになります。
写しを置くのは、ファイルが 20 MB 以下で、写し全体が 1 GB 以内に収まるあいだだけです。
それより大きいファイルは預け先に置いたままにし、記録はそこへリンクします。

写しは著者が預けたファイルそのものです。作品自身のライセンスのもとで、著者、ライセンス、原本へのリンクを添えて共有します。
受け付けるライセンスは、これを認めています。
著者は写しを外すよう求めることができます。その場合、記録は預け先へのリンクだけになります。

Sophaxis は毎週、著者全員が同意した作品について、Internet Archive に頁と PDF の写しの保存を求めています。このサイトが無くなっても読めるようにするためです。

記録の頁はどれも、Google Scholar が読む引用のタグを持ちます。
検索エンジンが頁を索引するかどうか、いつ索引するかは、Sophaxis には決められません。

## Sophaxis がライセンスを守るやり方

Sophaxis は、載っている作品を、作品自身のライセンスのもとで、そのライセンスが認める範囲でだけ共有します。
受け付ける三つのライセンスは、どれも、目的を問わず複製と共有を認めています。
写しを置くことと、それを配信することは、日本の著作権法第 21 条と第 23 条が著作権者に専有させている行いです。Sophaxis は、ライセンスが与える許諾に拠ってそれを行います。同法第 63 条は、許諾を得た者が、その許諾に係る利用方法及び条件の範囲内でだけ利用できるとしています。Sophaxis は、同法のどの例外にも拠りません。
ライセンスを与えた人がそれを与える権利を持っていなかったときは、そのライセンスはその許諾になりません。著者は投稿のときにその版を共有してよいことを確認し、[削除の規程](./takedown.ja.md)に沿った求めがあれば写しを外します。
CC BY 4.0 と CC BY-SA 4.0 は表示を求めます。CC0 1.0 は求めませんが、Sophaxis はそれでも著者を示します。

- 表示：記録の頁はどれも、著者と題を挙げ、ライセンスの名をリンク付きで示し、DOI で作品へリンクします。
- 改変しない：PDF の写しは、預けたファイルを 1 バイトも変えずに、そこに付いている告知ごと置いたものです。要旨は、書式のタグを外し、語を変えずに、素の文として示します。
- 条件を足さない：Sophaxis は、ライセンスが読者に認めていることを制限する条件も技術的な手段も足しません。
- 推薦を装わない：Sophaxis のどこにも、著者が Sophaxis やその作品の使い方を推薦していると述べたり、ほのめかしたりするものはありません。

## 学術誌が出版した作品

学術誌が作品を出版すると、著作権や独占的な許諾が出版者に移ることがあります。
その場合、著者は、預けた版をそのライセンスで共有してよいことを確かめなければなりません。
共有してはいけない場合、その作品は載せられません。

## 他人の素材

図・表・長い引用その他の他人の素材には、許諾が要ります。または、引用のように法令が認めるやり方で使わなければなりません。
その責任は著者が負います。

## 認めないことの例

これらの例は、この規程の当てはめ方を示すものです。すべてを挙げたものではありません。

共有する版について：

- 著作権が出版者に移ったのに、出版者の組版の版を CC BY で預けること。著者はもはやそれを許諾できません。
- 出版者が定めるエンバーゴが明ける前に、受理された原稿を預けること。
- 新しい草稿、手を入れた写し、学術誌の体裁のように、預けたファイルと異なる PDF を投稿の issue に添付すること。写しは、預けたファイルを手を加えずに置いたものでなければなりません。
- Sophaxis に PDF の写しを変えるよう求めること。変えるなら、預け先での新しい版になります。

他人の素材について：

- 書籍・論文・ウェブサイトから、許しを得ずに、引用の範囲を超えて写した図・表・地図・写真。
- 引用の法令が及ばない長さで引いた、ほかの作品の長い一節。
- 他人の詩・歌・短編の全文。
- 他人の論文の翻訳を、著者自身の作品として預けること、または原作の権利者の許しなく預けること。
- 再公開を禁じる条件のある資料館の画像。
- 非営利や改変禁止のライセンスの素材を、CC BY 4.0、CC BY-SA 4.0、CC0 1.0 の作品の中に、そのライセンスのもとにあるかのように置くこと。
- ソフトウェア、ウェブの頁、動画の画面写しを、引用として認められる範囲を超えて載せること。

求めについて：

- 公開の削除の issue で、侵害している素材そのものを繰り返すこと。代わりに、それがどこにあるかを書いてください。
- 預け先から預けたものを削除するよう Sophaxis に求めること。Sophaxis にはできません。その求めは預け先へ送ります。

## 侵害

載っている作品が自分の権利を侵害していると考える権利者は、[削除の規程](./takedown.ja.md)に沿って削除を求めることができます。
